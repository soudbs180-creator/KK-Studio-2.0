# 在 Figma 中继续修改

原始设计：<https://www.figma.com/design/0nU0A7pq6eyjwfwm1TtWkO/kk>。

这份补充包创建三张原生可编辑画板：资产搜索空态、创建主体、模型供应商空态。文字、输入框、按钮、布局均为 Figma 图层；不是截图。按原稿的 Inter、深色背景、边框与圆角延展。

1. 在 Figma 桌面端打开你的 kk 文件。
2. 从「插件 → 开发 → 从 manifest 导入插件」选择本目录 manifest.json。
3. 运行「KK Studio · 可编辑补充页面」。
4. 在新页面「KK Studio · 交互补充 2026-09-06」直接修改文字和布局。

不会修改或删除原始画板；重复运行会打开已有补充页面。插件不联网。

当前限制：Figma MCP 读取接口返回 Starter 调用额度已用完，后续连接工具也不再可调用。因此此包尚未在真实 Figma 中执行，不能算已回写或完成 Figma 视觉验收。JavaScript 语法和创建布局的离线结构已检查；导入后的字体与真实布局仍需检查。
