设置通用页按 900×700 原稿还原；其它设置分类显示具体配置表单及服务未接入说明。“模型供应商”按 API 连接配置实现，包含供应商名称、API Base URL、当前会话 API Key 与默认模型。只保存非敏感连接元数据，密钥不进入 localStorage；测试连接由用户点击触发，请求 `<Base URL>/models`，显示 idle/loading/success/error/cancelled/offline 六种状态。资产支持搜索、类型/标签/时间筛选、网格/列表、选择预览、画布/资产切换、展开/收起、创建主体、本地图片导入。未接入后端的操作明确标记为前端演示，不伪造生成结果或服务器保存。

主工作台使用无滚动条的无限画布：选择工具下左键从空白起拖为框选，中键/右键或抓手工具平移；滚轮围绕指针位置缩放，节点卡片可用鼠标、触控或触控笔拖动。卡片内的按钮、输入框和下拉控件保留自身操作，不触发节点移动；键盘用户聚焦卡片后可用方向键微调。节点移动时连接线必须同步更新。手势与快捷键以 `UI-STANDARDS.md` 的“最新用途和复用契约”为准。

卡片编辑器属于节点选中态，不能常驻画布。默认只显示卡片；一次点击（指针位移不超过 4px）或聚焦后按 Enter/Space 选中节点，图片卡片的提示词编辑器显示在卡片下方。点击另一张卡片切换选中项，点击画布空白或按 Escape 取消选择；拖动超过阈值只移动卡片，不触发展开。图片预览面本身用于选择和拖动，上传只由“上传图片”、编辑器内虚线“＋”或文件拖放触发。编辑器内部布局以用户提供的 `docs/reference/user-image-composer-selected.png` 为基准：虚线“＋”位于左上，提示词位于其下，模型、参数、语音、数量和生成控件贴底排列。

底部工具栏箭头是选择/抓手菜单入口，心形打开全局喜欢收藏，不依赖当前选中节点；“＋”使用共享添加节点菜单，支持的节点有真实入口，未支持项禁用并说明原因。新增卡片支持拖动、方向键微调与 Delete/Backspace 删除。旧“收起工具栏、心形切换选中卡片收藏、左下缩放恢复全部节点”的要求已被后续 `UI-STANDARDS.md` 和 `UI_SPEC.md` 覆盖，不得重新实现。现有结果卡片收藏继续使用共享收藏状态。
