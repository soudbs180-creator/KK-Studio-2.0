主工作台使用无滚动条的无限画布：空白区域拖动用于平移，滚轮围绕指针位置缩放，节点卡片可用鼠标、触控或触控笔拖动。卡片内的按钮、输入框和下拉控件保留自身操作，不触发节点移动；键盘用户聚焦卡片后可用方向键微调。节点移动时连接线必须同步更新，并提供一键恢复初始布局。

卡片编辑器属于节点选中态，不能常驻画布。默认只显示卡片；一次点击（指针位移不超过 4px）或聚焦后按 Enter/Space 选中节点，图片卡片的提示词编辑器显示在卡片下方。点击另一张卡片切换选中项，点击画布空白或按 Escape 取消选择；拖动超过阈值只移动卡片，不触发展开。图片预览面本身用于选择和拖动，上传只由“上传图片”、编辑器内虚线“＋”或文件拖放触发。编辑器内部布局以用户提供的 `docs/reference/user-image-composer-selected.png` 为基准：虚线“＋”位于左上，提示词位于其下，模型、参数、语音、数量和生成控件贴底排列。

底部工具栏按 Figma 组件状态工作：上箭头收起工具栏、下箭头重新展开；“＋”展开图片卡片、视频卡片和资产三个真实入口，新卡片放在当前视口中心并立即进入选中态；心形只对当前选中卡片启用并切换该卡片的收藏状态，没有选中项时禁用并说明原因。新增卡片支持拖动、方向键微调与 Delete/Backspace 删除。收藏页和全局搜索从同一份画布收藏状态读取，删除卡片同时移除其收藏。左下角缩放百分比负责恢复平移、缩放、基础节点位置和选择状态，不能再把工具栏展开按钮复用为复位操作。
