## 观察到的交互

- 侧栏的项目列表项都带有置顶和更多操作入口。更多菜单包含“重命名”“移入项目”“复制路径”“在文件资源管理器中打开”“关闭项目”“删除”，菜单中删除操作使用危险色。
- 画布上方保留缩放、整理、网格/点阵、连线和小地图控制，底部工具栏保留添加、选择/抓手、喜欢、资产和帮助入口。通过画布设置可以直接在点阵、网格和纯色之间切换，设置面板同时提供默认、暖灰和冷灰背景色。
- 文本卡使用卡片内的动作列表表达下一步意图：先显示“试试：”，再提供“自己编写内容”“剧本生成”“策划案生成”“提示词生成”。动作按钮位于文本卡内容区，而不是把用途藏在一个不明确的生成按钮里。
- 右侧新建对话区的空态与输入区分开；输入区底部的模型、Skill、自动模式和发送按钮保持同一行，未输入时发送为禁用态。
- 画布节点空态使用统一的深色媒体占位容器；图片和视频保留语义图形，但外框、尺寸和视觉权重一致。
