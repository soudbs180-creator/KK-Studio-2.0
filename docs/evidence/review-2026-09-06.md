# 本轮自审与独立复查

范围：新工程前端，不改旧数据、不恢复 Plate 卡、不接后端。

1. 完整性：设置/资产原稿具备入口与交互；模型供应商已改为 API 连接表单，画布可新增图片/视频卡片，收藏和搜索读取画布状态。缺失业务列在 PROGRESS，不将页面壳当作业务完成。
2. 正确性：修复导航卸载草稿；保留当前会话；参数与过滤来自状态，资源包运行时校验。根据用户补充图将图片编辑器改为卡片选中态，默认隐藏，点击显示，切换节点或点击空白收起；纠正工具栏箭头误绑复位和心形误绑页面跳转。
3. 健壮性：资源错误为中文恢复指引；取消文件选择有反馈；组件关闭后不写回已取消导入。
4. 结构：设置分类、供应商连接、资产导入、创建主体分离；画布模型、交互 hook 和工具栏从主组件拆分，表现组件控制在 300 行以内。
5. 性能：首屏 JS gzip 90.57 KB，导入限制单文件 10MB / 每次 20 个；未测大规模节点，保留 Prototype。
6. 安全：模型连接测试只在用户点击后请求其配置的 HTTP(S) 地址；API Key 只保留在组件内存，不写 localStorage、导出文件或日志。供应商元数据和偏好均由 Zod 校验；开发依赖审计零报告。
7. 验证：画布浏览器用例新增默认隐藏、鼠标点击展开、其它卡片收起、键盘 Enter 展开/Escape 收起、拖动不展开、编辑器 590×237 坐标、工具栏 266↔50 展开收起及收藏状态断言；选中态截图为 `docs/evidence/image-composer-selected.png`。
8. 反思：本轮消除了主工作区重复 inset 造成的系统性偏移，并用节点数据代替目测定位。主稿仍有图标及字体渲染差别。Figma 授权失效时只保存 oEmbed 文件缩略图；浏览器显示最新打开节点 `253:563`，但不能把它写成最新远端画板的节点级验收。

独立复查问题：会话丢失、响应式对话不可达、嵌套弹窗焦点、列表/网格图标映射、节点仅支持鼠标、输入框拖选误触节点、节点移动后连线不跟随。修复后进行了对应回归用例。

续轮复查：新增回归先复现了四类失败——删除前节点后后节点草稿串位、编辑区被工具栏遮挡、390px 下新增按钮在屏幕外，以及 HTML 200 响应被误判为模型 API 可用。分别通过稳定 key、按完整编辑区适配视口、修正响应式选择器优先级、验证模型列表 schema 修复。进一步检查了取消/编辑后旧请求不覆盖状态、配置分类直达和新增菜单 Escape。最终 `npm run verify` 退出码 0，12 项核心测试和 20 项 Edge 测试通过。连接用例使用受控响应，未联系真实供应商；截图 `settings-model-provider.png`、`canvas-added-card.png`、`collection-from-canvas.png` 已人工视觉复核。浏览器结果见 `browser-results.json`。新 Figma 页面仍未获得节点级上下文，不能声明全部页面验收完成。
