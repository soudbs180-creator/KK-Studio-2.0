## 尚存差异与缺陷

1. 窄屏没有把初始世界视图适配到可见区域，图片与两个视频节点仍按桌面坐标放置；虽然页面 `scrollWidth` 不溢出，但用户首次看到的是被裁切的卡片。
2. `Modal` 只有入场动画，关闭时 React 立即卸载，因而没有原型式的离场过渡；需要引入可取消的 closing 状态并延迟卸载，同时保持 Escape 回焦。
3. 顶部导航、聊天面板、生成数量和编辑器仍有中文字体回退及字形栅格化差异，需同状态截图逐项校对。
4. Figma 原型的工具栏悬停反应已读取到 300ms，但当前实现只映射颜色/滤镜过渡，尚未逐状态复刻原稿变体的图标/背景变化。
5. 本地演示生成默认数量为 8，会一次创建 8 个结果卡片；这是当前测试素材状态，视觉上与空白原稿状态不同，不能作为服务生成完成态。
