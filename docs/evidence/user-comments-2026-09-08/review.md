范围：用户最新10条批注中的鼠标映射、底栏选择/抓手、心形入口、对话图标、帮助菜单，以及用户补充的快捷键面板。此单元为Prototype，整体仍Repairing；其余批注没有冒认完成。

1. 完整性：左键框选、中右键/抓手平移、Shift追加多选/一起拖动、Space临时平移、V/H、Escape取消均有实际浏览器操作。底栏心形无需节点选择，直接打开喜欢收藏搜索；帮助先打开教程/快捷键菜单。保持原节点移动、输入和草稿行为。

3. 健壮性：输入中的H/V/Space不改变工具；取消恢复起点；指针取消/窗口失焦清除手势；菜单互斥、上下键/Home/End、Escape回焦；弹窗从持久入口接收并恢复焦点。真实触屏与大规模节点性能尚未验收。
4. 结构：CanvasMarquee单独负责框选显示与操作说明，Canvas保持300行以内；工具条、快捷键和手势各自独立。新增颜色集中于ui-tokens，未扩大遗留基线。

6. 安全：未增加API请求或后台服务，没有伪造服务生成/扣费/保存；未删除旧工程、历史资源或用户数据。仅把本轮误命名且未使用的253:512剪刀资源更名connection-cut.svg，未用于加号。
