# KK Studio 页面类型模板（新版 Figma 治理基线）

> 本文件只负责一级页面模板。零件尺寸和状态规则见
> [`UI_RULES.md`](./UI_RULES.md)，模板的完整 Figma 来源见
> `docs/changes/2026-09-29-figma-ui-governance/spec.md`。

## 1. 只有五种一级模板

| key | 结构 | 交互 | 视觉参数与适用条件 |
| --- | --- | --- | --- |
| `list` | 工具栏 → 表头 → 行列表 → 分页 | 排序、筛选、选择、批量操作；行操作保持可见 | 适合字段规整、数量大、需要快速比较 |
| `grid` | 工具栏 → 响应式栅格 → 媒体/标题/元信息/操作 | 悬浮操作、多选、整卡进入详情 | 工作展示和媒体结果的默认模板；适合横向浏览 |
| `detail` | 标题区 → 主内容 + 属性栏 → 固定主操作 | 编辑、保存、复制、返回；属性栏独立滚动 | 单个对象需要完整理解或编辑时使用 |
| `timeline` | 筛选 → 阶段/时间轴 → 状态节点 → 事件卡 | 展开失败原因、过滤、行内重试 | 任务、版本、审批等有顺序的过程 |
| `gallery` | 胶片/栅格 → 稳定比例媒体 → 沉浸式预览 | 预览、键盘切换、缩放、元信息开关 | 图片/视频为主且需要沉浸式复核 |

运行时定义位于 `src/domain/pageTemplates.ts`，机器可读描述位于
`src/styles/archetypes.json`，共享样式位于 `src/styles/page-templates.css`。

## 2. 选型规则

按以下顺序命中一个一级模板：

1. 有时间或因果顺序的过程 → `timeline`。
2. 单个对象需要完整编辑或检查 → `detail`。
3. 图像/视频为主并需要沉浸式预览 → `gallery`。
4. 需要大量字段、排序或批量操作 → `list`。
5. 其他工作展示、技能、项目、工作流和媒体结果 → `grid`。

工作展示明确默认 `grid`。选型函数只接受内容特征，不接受页面私有 CSS 参数，
因此同一类新功能会自然复用现有结构。

## 3. 组合和嵌套

- 混合页只能声明一个 `primary` 模板。
- `detail` 可以作为 `grid` 或 `gallery` 的嵌套详情区域。
- `list`、`grid`、`timeline` 不得作为同一层的多个 peer-level 主布局。
- 页面模板不能通过临时增加卡片网格、时间线或列表来规避选型；应先更新内容
  特征，再由注册表返回已有类型。

## 4. 共享状态和组件形态

所有模板都实现空、加载、错误三态，并遵守 `UI_RULES.md` 的唯一主操作、文字
截断、键盘焦点和错误反馈约束。

### `list`

- 顶部保留搜索/筛选/排序工具栏；行内操作不依赖悬浮才可见。
- 对比型数字列使用等宽数字并保持右对齐。
- 加载保持至少三行的几何，错误行带原因与重试。

### `grid`

- 卡片采用稳定媒体比例、标题、两到三行说明、状态和操作槽。
- 多选与详情入口不改变卡片外壳尺寸；悬浮只改变操作显隐。
- 新增“工作展示”功能默认使用此模板，不新增平级卡片类型。

### `detail`

- 返回入口固定在标题区；属性栏与主内容分离滚动。
- 保存是唯一 Primary，复制、返回和删除使用次级或危险变体。

### `timeline`

- 时间轴节点按业务状态排序，当前节点始终有可见状态文本。
- 失败节点展开显示原因、影响和恢复动作，重试不得创建重复任务。

### `gallery`

- 媒体比例稳定，预览层不改变底层列表/栅格位置。
- 键盘左右切换、Escape 关闭，元信息和操作不覆盖媒体主体。

## 5. 新功能模板配置

```ts
import { selectPageTemplate } from "../src/domain/pageTemplates";

const template = selectPageTemplate({ workDisplay: true });
// template === "grid"
```

新增功能提交前必须填写：

- 内容特征和选中的 `PageTemplateKey`；
- 主模板之外的嵌套区域及其原因；
- 空/加载/错误态和主操作；
- 复用的 token、组件类和浏览器证据。

如果无法匹配五种模板，先补充内容特征或提出治理页面变更，不得直接新增第六种
模板或在页面 CSS 中复制已有布局。
