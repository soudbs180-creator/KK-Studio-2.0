# KK Studio UI 类型目录（Archetype Catalog）v1.0

> 定位：**新增任何功能前，先在这里选类型，再写代码。**
> 本文件是 `UI_RULES.md` 的上层——`UI_RULES.md` 管"零件怎么长"，本文件管"用什么零件拼成什么页面"。
> 完整索引与冲突裁决见 [`UI_INDEX.md`](./UI_INDEX.md)；本文件的代码形态是 `src/styles/archetypes.css` / `archetypes.json`，两者必须同步。
> 机器可读版本：`src/styles/archetypes.json`（含路由规则，供自动生成消费）
> 可直接引入的实现：`src/styles/archetypes.css`

---

## 0. 新增功能的固定三步流程

```
Step 1  回答 §3 路由决策树 → 得到类型 ID（A1–A9）
Step 2  复制该类型的「布局结构 + 组件形态 + 交互 + 视觉参数」四张表
Step 3  按 §6 检查清单自检，任何一条不过不许合入
```

**铁律**
1. 不得新增本目录之外的 UI 类型。特征匹配不上时，取最接近的一个并说明理由，不允许自创。
2. 类型确定后，**布局参数（列宽/gap/内边距/圆角）直接读表，不得现场调值**。
3. 同一页面**只允许一种主类型**；允许的唯一组合见 §3.2。
4. 每个类型必须同时实现三态（空/加载/错误），见 §2.10。

## 1. 通用页面外壳（Page Shell）—— 所有新功能共用

| 区域 | 参数 |
|---|---|
| 顶栏 | 高 40（`--topbar-height`） |
| 侧栏 | 宽 291（`--sidebar-width`），紧凑态 61 |
| 内容区外边距 | 24（标准）；≥1440 用 40；≤768 用 16 |
| 区块间距 | 32 |
| 页面标题 | `title-lg` 24 / 32，SemiBold，`text-primary` |
| 页面副说明 | `body` 13 / 20，`text-tertiary`，标题下方 8 |

工具行的组件只允许：`Input md 32` / `Select md 32` / `Capsule sm 28` / `IconButton md 32`。

## 2. 类型目录

### A1 · Gallery 画廊网格

**适用**：成果是图片/视频等视觉素材，用户行为是"扫视挑选"而非"逐条阅读"，条目通常 > 12。
**判定**：主对象是位图或视频 **且** 需要批量浏览/挑选/灯箱。
**不适用**：条目需要读标题和描述才能区分 → 转 A2。

| 项 | 参数 |
|---|---|
| 栅格 | `repeat(auto-fill, minmax(180px, 1fr))`；≤900 降 `minmax(140px,1fr)`；≤600 降 `minmax(110px,1fr)` |
| 间距 | gap 12（栅格）／卡片内 padding 4 |
| 卡片圆角 | 12；缩略图圆角 **8**（12 − 4 = 8 ✓） |
| 缩略图 | `aspect-ratio: 1/1`，`object-fit: cover`，`bg-input` |
| 元信息 | 11 / 14，`text-tertiary`，文件名最多 2 行，`text-overflow: ellipsis` |
| 角标 | Badge 20，左上内嵌 6；AI/来源角标用 `accent-soft` 底 + 配对的 `text-on-accent-soft`，确保文字可读 |
| 选态 | 1px `border-accent` + `inset 0 0 0 1px accent`；**不用背景色变化**表达选中 |
| 交互 | 单选点击／Cmd 加选／Shift 连选；hover 出现右上角操作 IconButton 28；双击或 Enter 开灯箱；方向键移动焦点 |
| 动效 | hover 缩略图 `scale(1.02)` 140ms；批量进入 `surface-enter` 220ms |
| 配套 | 灯箱：全屏 `bg-overlay`，关闭按钮 IconButton 32 右上，左右切换 IconButton 40，底部文件名 + 操作条 |

### A2 · CardGrid 卡片网格 —— **默认类型**

**适用**：条目带标题 + 描述 + 状态，需要阅读与横向比较（工作流、技能、项目、连接器、模板）。
**判定**：每个条目 ≥ 3 个信息字段，且不止一张图。**匹配不上其他类型时一律用 A2。**

| 项 | 参数 |
|---|---|
| 栅格 | `repeat(auto-fill, minmax(240px, 1fr))`；≤900 降 200；≤600 单列 |
| 间距 | gap 16；卡片 padding 12；卡内区块间距 8 |
| 卡片 | radius 12，`bg-card`，1px `border-subtle`；hover → `bg-elevated` + `border-default` |
| 卡片头 | 图标 20 + 标题 14 / 22 SemiBold（间距 8）；右侧状态 Badge 24 |
| 描述 | 12 / 16，`text-secondary`，2 行截断 |
| 卡片底 | 元信息 11 / 14 tertiary 在左，操作 Button sm 28 在右；分隔用 8 |
| 交互 | 整卡可点 = 打开详情；卡内按钮 `stopPropagation`；Tab 可达，Enter 打开 |
| 动效 | hover border/background 140ms；进入 `surface-enter` 220ms |
| 选态 | 同 A1（描边，不用背景色） |

### A3 · ListTable 列表 / 表格

**适用**：字段规整、需要排序筛选，或条目 > 50 需要快速扫描（文件、用量、任务清单、连接状态）。
**判定**：字段 ≥ 3 **且** 需要排序；或数量大到网格不可用。

| 项 | 参数 |
|---|---|
| 行高 | 32（标准）／28（紧凑，由工具栏切换）；表头 32 |
| 列间距 | 16；首列预留 24 图标槽（无图标留空槽，文字左缘不变） |
| 表头 | 11 / 14，`text-tertiary`，不加粗；`position: sticky; top: 0` |
| 行态 | hover `bg-elevated`；selected `accent-soft` + 左侧 2px accent 条 |
| 数值列 | 右对齐 + `font-variant-numeric: tabular-nums` |
| 排序 | 点击列头三态循环：升 → 降 → 取消；箭头图标 14 |
| 行内操作 | **常驻在行尾**（不 hover 才出现——全站统一为常驻，避免"扫不到"） |
| 空/加载 | 容器保持 ≥ 3 行高度，避免切换时布局跳动 |

### A4 · Detail 详情

**适用**：单个对象的完整信息（素材详情、任务详情、技能详情、结果详情）。

**形态一 · 面板式**（侧栏/右侧抽屉）

| 项 | 参数 |
|---|---|
| 宽度 | 264（窄）／470（宽，含大预览时） |
| Hero | 缩略图 `aspect-ratio: 16/9`，radius 8 |
| 元信息表 | 标签列宽 80，11 / 14 tertiary；值 13 / 20 primary；行高 28 |
| 区块 | 间距 16；区块标题 12 / 16 SemiBold tertiary |
| 操作条 | 底部固定，主操作 `lg 40` 通栏，次操作 `md 32` 并排（间距 8） |
| 动效 | 从右滑入 220ms（复用 `conversation-panel-enter`） |

**形态二 · 整页式**：主区 `max-width: 720` 居中，或左主右辅 2:1；区块间距 32；区块标题 16 / 24。
**交互**：返回入口固定在左上；编辑走就地编辑；破坏性操作置于最底部且 `danger` 语义。

### A5 · Timeline 时间线

**适用**：有顺序/过程/历史（任务执行步骤、版本记录、审批流）。
**判定**：条目之间有**时间或因果先后**，且用户关心"走到哪一步"。

| 项 | 参数 |
|---|---|
| 布局 | 纵向单列；轴线 2px 在左（`border-subtle`）；图标槽 20 |
| 节点 | 圆点 8 + 2 描边；内容左缩进 32 |
| 步骤卡 | radius 8，padding 12；步骤间距 16 |
| 状态色 | 完成 `success`／进行中 `accent`（脉冲）／失败 `danger`／待处理 `tertiary` |
| 文本 | 步骤标题 13 / 20 SemiBold；说明 12 / 16 secondary；时间 11 tertiary 右对齐 |
| 交互 | 长内容默认折叠，点击展开；当前步骤自动 `scrollIntoView` |
| 动效 | 新节点 `surface-enter` 220ms；进行中点脉冲 1.6s `ease-in-out` 循环 |

### A6 · Board 看板

**适用**：对象按**离散状态分组**且需要在状态间流转（任务队列、审核队列）。
**判定**：存在一个明确的枚举状态字段，且主要操作是"把条目挪到下一状态"。

| 项 | 参数 |
|---|---|
| 列宽 | 264 固定；列间距 16；横向可滚动 |
| 列头 | 14 / 22 SemiBold + 计数 Badge 20；可折叠 |
| 卡片 | radius 8，padding 12；卡间距 8 |
| 拖拽态 | 拖拽中 `opacity: 0.6`；落位显示虚线占位框 radius 8 |
| 列内 | 超过 20 张列内滚动，列头 sticky |
| 动效 | 拖拽跟随 140ms；落位 220ms |

### A7 · Compare 对比

**适用**：同一对象的**多个版本/方案**并置比较（生成结果 A/B、重绘前后、多模型输出）。
**判定**：一次展示的是"同一个东西的 N 个变体"，而不是 N 个不同对象。

| 形态 | 参数 |
|---|---|
| 并排 | 2–4 列等宽，gap 16；顶部固定标签条（Chip 28）；同步滚动与同步缩放 |
| 滑块 | 单容器 + 可拖分割线：线宽 2 `accent`，手柄 32×32 radius 999；键盘左右 1%（Shift 10%） |
| 标注 | 每格左上版本 Badge 20；右下角主操作 Button sm 28 |

### A8 · Stats 指标面板

**适用**：数量、额度、趋势（用量统计、生成次数、存储占用）。
**判定**：主体是**聚合数值**而非对象列表。

| 项 | 参数 |
|---|---|
| 栅格 | `repeat(auto-fill, minmax(200px, 1fr))`，gap 16 |
| 指标卡 | padding 16，radius 12，`bg-card` |
| 数值 | `display` 32 / 40，SemiBold，`tabular-nums` |
| 标签 | 11 / 14 tertiary，数值上方 |
| 变化量 | 12 / 16；**通用指标：上升 `success`／下降 `danger`**；**行情/金融场景例外：涨红跌绿** |
| 图表 | 色板取 accent 序列，**最多 6 色**；网格线 `border-subtle`；不引入新图表库配色 |

### A9 · Canvas 节点画布（既有特例，登记以防滥用）

**适用**：对象之间存在**空间关系或连线依赖**（工作流图、节点编排）。
**判定**：需要"自由摆放 + 连线"才用。**除此外一律用 A1–A8。**
参数：节点 radius 12；连线 2px；选中 ring 2px accent；网格点 1px；悬浮工具条 padding 4 / radius 12 / 内按钮 28。

### 2.10 三态（每个类型必须同时实现）

| 态 | 规范 |
|---|---|
| **空** | 容器最小高 240；居中；图标/插画 48 + 说明 13 / 20 `text-secondary` + 主操作 `lg 40`；**禁止只写"暂无数据"** |
| **加载** | 骨架块复用目标元素的**圆角与尺寸**（如 A1 骨架 radius 8）；脉冲 1.6s；列表骨架 ≥ 3 行；**只在按钮内用 spinner** |
| **错误** | 行内卡片 radius 8 padding 12，`danger` 边框；说明 + 重试 Button `md 32`；不整页报错除非影响整个页面 |
| **局部不可用** | `disabled` + tooltip 说明原因（见 `UI_RULES.md` §1.1） |

## 3. 路由规则

### 3.1 决策树（按顺序命中即停）

```
1  对象之间有空间/连线关系？              → A9 Canvas
2  要比较同一对象的多个版本？              → A7 Compare
3  主体是聚合数值/趋势？                   → A8 Stats
4  条目之间有明确先后顺序/过程？           → A5 Timeline
5  存在枚举状态且主要操作是跨状态流转？    → A6 Board
6  主对象是图/视频且需要扫视挑选？         → A1 Gallery
7  字段规整且需排序，或数量 > 50？         → A3 ListTable
8  是单个对象的完整信息？                  → A4 Detail
9  其他                                    → A2 CardGrid（默认）
```

> 顺序说明：2–5 是**强特征**，优先于 6–7 的载体特征。例如"生成结果对比"虽然主体是图片，但要先判为 A7。

### 3.2 允许的组合（仅此三种）

| 组合 | 说明 |
|---|---|
| **A1 / A2 + A4 面板式** | **"工作展示"的标准形态**：左网格、右详情面板。详情随选中项更新 |
| **A1 / A2 + A3** | 网格/列表视图切换（同一个数据集的两种呈现，共用筛选与选中态） |
| **A8 + 任一** | 指标面板作为页面顶部的概览条，高度不超过内容区 1/4 |

### 3.3 禁止的组合

- 🚫 同一页面并列两种网格类型（A1 与 A2 混排）
- 🚫 A5 / A6 与网格并列（时序与空间两种心智模型冲突）
- 🚫 同一数据集同时存在三态以上呈现
- 🚫 为单一功能引入新的栅格列数或 gap 值

## 4. 视觉参数总表（跨类型统一）

| 类别 | 取值 | 备注 |
|---|---|---|
| 栅格 gap | 12（A1）／16（A2·A6·A7·A8） | 仅此两值 |
| 卡片内边距 | 4（A1）／12（A2·A5·A6·错误态）／16（A8） | 圆角 12 必须配 4 或 12，不得配 10 |
| 圆角 | 8（小卡/骨架/缩略图）／12（标准卡/面板/Gallery 卡）／28（大卡）／999（Badge·Chip） | 见 `UI_RULES.md` §4.2 嵌套公式 |
| 字号 | 11 元信息／12 描述·次级／13 正文·列表／14 卡片标题／24 页面标题／32 数值 | 产品内封顶 24；32 仅用于 A8 数值 |
| 配色层级 | `bg-app` → `bg-card` → `bg-elevated` → `bg-overlay` | 逐级不跳级 |
| 强调色 | 一屏一次；选中用描边不用填色 | 见 `UI_RULES.md` §5.4 |
| 动效 | 微交互 140ms；面板/进入 220ms；缓动 `cubic-bezier(0.22, 1, 0.36, 1)` | `motion-toolbar` 300ms 回弹**仅限画布工具栏**，不得推广 |
| 无障碍 | 全类型支持键盘可达 + `focus-visible` ring 2px/offset 3px；`prefers-reduced-motion` 下关闭动效 | 已有全局兜底 |

## 5. 机器可读配置

`src/styles/archetypes.json` 含：类型表（id / 判定特征 / 全部数值参数）、路由规则（可执行顺序）、禁止组合、三态规范。
自动生成新功能时**直接读该文件**，不要重新推导样式。
`src/styles/archetypes.css` 提供对应实现类（`.kk-gallery` / `.kk-cardgrid` / `.kk-table` / …），引入即用。

## 6. 新增功能检查清单

- [ ] 已按 §3.1 决策树确定类型，且未自创新类型？
- [ ] 栅格 gap、卡片内边距、圆角是否**直接取自类型表**？
- [ ] 圆角是否满足嵌套公式（内 = 外 − 内边距）？
- [ ] 该类型的**空 / 加载 / 错误**三态是否都实现了？
- [ ] 选中态是否用**描边**而非背景色？
- [ ] 组件档位是否落在 `UI_RULES.md` §2 的五族封闭高度轴内，且同一容器内不跨档？
- [ ] 是否引入了新的颜色/字号/间距/圆角字面量？
- [ ] 页面是否只有一个主操作？视图切换是否被误当作主操作？
- [ ] 键盘可达 + `focus-visible` 是否覆盖？
- [ ] 若与既有类型组合，是否属于 §3.2 允许的三种之一？
