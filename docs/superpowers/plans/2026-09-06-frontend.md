# 最新 Figma 页面实施计划

> For agentic workers: 使用 superpowers:subagent-driven-development；设置子任务可独立实施，主集成者负责界面壳、资产管理、Figma 和最终验证。

Goal: 从静态草稿推进为符合最新 Figma 的前端交互原型。
Architecture: 保留 React/Vite；App 管理弹窗入口；设置与资产组件互相独立；共享原稿颜色令牌和图标。
