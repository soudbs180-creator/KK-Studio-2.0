# 前端规范与多模态演示设计

2026-09-07 用户追加授权：可复用的 UI 标准、校正细小偏差、统一颜色/图标、完成点击/弹层/右侧跟随加号/连线删除、以图片视频文案音频示范素材验证生成后的展示。仅前端，不接后端/API、不发布。此文为既有前端纠偏的 extend，不替换历史实现。

## 设计决定

- 延续 Figma 中性深色画布、卡片和面板几何。现有导出图标优先；缺失图标使用 Iconsax 同一线性集合，建立语义名称到资源的映射。禁用、危险、选中、成功、加载、离线、焦点分别使用语义颜色令牌，页面不得临时调色。
- 卡片右侧加号跟随节点坐标和缩放，点击打开共享类型菜单。选类型创建下游卡片与连线，新增节点可见且被选中；不改变来源卡片位置或草稿。连线悬停/聚焦/选中显示删除按钮；只删除连接，提供撤销，保留两端内容。
- 保留默认空白工作台。新增显式“示范素材”入口，可加载图片、短视频、音频、可编辑文案。所有示范节点显示“示范素材”，模拟处理显示“演示处理中”，不冒认供应商生成成功、积分消费或保存到服务器。
- 结果卡片共用预览、下载/复制、收藏、继续创建和删除行为。图片支持放大；视频/音频使用真实媒体控件、加载/错误提示；文案支持编辑与复制。弹层 Escape 和关闭按钮回焦，菜单操作不触发拖动，示范处理可取消/重试；文案可在页面已加载时离线试用，媒体离线时提示恢复连接后重试。未实现 Service Worker 完整离线缓存。
- 现有卡片通过显式“试用示范”流程查看本地结果；真实生成入口仍如实提示 API 未接入。媒体资源来源和合成方式写入清单，音视频不得仅放海报假装可播放。
