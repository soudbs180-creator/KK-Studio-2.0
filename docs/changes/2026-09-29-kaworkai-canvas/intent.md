## 用户原意

先了解参考站点有哪些功能和交互，以及这些能力可能如何实现；只把稳定、适合本地架构的部分合并进 KK Studio，UI 仍遵循本地设计系统。调研过程尽量不消耗参考站点的 50 积分。

## AI 工程转译

对参考站点做只读交互审计，记录节点菜单、画布控制、图层/小地图、整理、快捷键、持久化和撤销模型。对照本地 `Canvas`、`canvasGraph`、`projectCanvas` 与 UI 规则，优先补齐不依赖远程模型或付费点数的画布基础能力：画布快照历史、键盘/右键撤销重做、网格吸附设置持久化、轻量图层检索面板。远程生成工具、积分扣费和竞品的视觉样式不进入本轮。

## 目标与非目标

- 预期结果：用户在 KK Studio 画布中能用熟悉的撤销/重做、网格吸附和图层定位交互，并且设置在同一浏览器会话重开后保留。
- 包含范围：画布快照历史；Ctrl/Cmd+Z、Shift+Z/Ctrl+Y；右键菜单动态撤销/重做；可关闭的网格吸附；图层搜索、定位、选中；研究记录和功能文档。
- 明确不包含：调用 kaworkai 的生图/去背景/精修/海报/多角度工具；购买、消耗或模拟积分；复制竞品 CSS、颜色或布局；云端同步、多人协作、分组折叠数据模型。
- 受影响平台/模块：Web 与 Tauri 共用的 `src/components/Canvas.tsx`、`src/components/canvas/`、`src/domain/`；画布快照仍沿用现有项目快照持久化。
- 已有实现和规范来源：`docs/UI_INDEX.md`、`docs/DESIGN-SYSTEM.md`、`docs/UI_RULES.md`、`docs/features/feat-001-canvas-workbench.md`、本地画布源码，以及只读站点审计记录 `research.md`。

## 假设、风险和决策

- FACT（直接证据）：参考站点页面预建了图层、整理、小地图、快捷键、撤销相关 UI；本地项目已有节点/连线/小地图/缩放，但右键撤销重做当前为禁用占位。
- INFERENCE（假设及风险）：本地项目没有分组模型，因此图层面板先做平铺检索；未来引入分组时再扩展同一入口，不伪造分组能力。
- UNKNOWN / CONFLICT：参考站点的远程模型工具和真实云端保存未在本轮触发或认证；不能据此判断其服务端实现细节。
- AI 自主决定的技术事项及理由：历史采用画布快照栈，统一覆盖 items/positions/edges/viewport，复用现有项目持久化；偏好只保存非敏感 UI 状态；入口沿用 KK 现有右键菜单与画布浮层以满足严格几何门禁。
- 必须由用户决定的产品语义/范围事项：无；用户已授权研究并合并本地适用能力。
- 外部条件、费用或不可逆动作及已有授权：只读访问参考页面；本轮不执行生成、上传、分享、购买或积分消耗。
- 不在本次范围的问题与账本 ID：真实视频/音频/ComfyUI 工具、云端同步、分组折叠，沿用 FEAT-001 与现有相关任务记录。
