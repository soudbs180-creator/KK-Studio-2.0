## 取舍

值得合并的是交互基础设施：状态可逆、快捷键、吸附偏好、图层定位。这些不依赖参考站点积分，也能直接提高本地画布的可控性。AI 工具、支付点数、服务端 board API 和竞品视觉规范不复制，避免形成第二套 provider 或 UI 体系。

## 脚本级实现核对

以下细节来自页面公开脚本的只读阅读，用来判断交互背后的状态模型，而不是照搬界面。

### 底部控制条与网格

- 控制条偏好使用 `ai-canvas-dock-v1` 保存，初始值是 `snap: false`、`minimap: false`、`edges: true`。每次切换都会立即写入本地存储并给出状态提示。
- 网格不是固定屏幕像素。世界坐标基准步长为 24，脚本根据缩放把屏幕间距保持在 16–32 像素，并带有 0.05 的迟滞，避免缩放临界点来回跳级。
- 拖动和调整尺寸都会吸附；按住 Ctrl/Cmd 会为当前手势临时绕过吸附。小地图点击或拖动会把视口中心移到对应世界坐标；缩放菜单还包括适应画布、选中项铺满和实际大小。

### 历史记录与保存

- 画布快照包含标题、节点、连线和视口，历史最多 80 条，同时受序列化后 24 MB 总字节数限制。新操作会清空 redo，重复快照不会入栈。
- 撤销/重做使用 `applyingHistory` 保护，恢复快照后仍会走正常保存路径；服务端或多标签同步失败时保留本地快照。
- 保存采用约 360 ms 防抖，版本快照另有 30 条上限。这个分层说明了“会话内撤销”和“可恢复版本”应当是两个状态容器。

### 图层面板

- 图层侧栏偏好使用 `canvas-side-v1` 保存，支持全部/分组/图片三个筛选、列表/网格两种视图和 1–5 的缩略图尺寸。搜索输入约 120 ms 防抖，并对命中标题做高亮。
- 缩略图按需加载；点击条目会展开所在组、选中对象并把它定位到视口。侧栏打开后会把搜索框聚焦。
- 画布可用宽度低于 360 px 时，脚本会在图层侧栏和对话面板之间互斥，避免两个浮层把画布挤到不可用。本地没有分组数据，因此只实现平铺搜索和定位。

### 整理、端口与快捷键

- 整理菜单不是单一按钮，而是“仅整理位置”“整理并分组”“整理并折叠”三种策略，另有紧凑/舒适/宽松间距。布局成功后写入历史并保存，空操作会提示当前已经整齐。
- 连线在命中半径、吸附半径和端口类型上分别校验：拒绝自连、重复边、单入口占用、循环和不匹配的 prompt/text/source 端口；无效拖放会保留当前图，不偷偷创建边。
- 快捷键命令表包含 Ctrl/Cmd+C/V/A/Z、Shift+Z 或 Ctrl/Cmd+Y、Ctrl/Cmd+S、Delete、Esc、Space 临时平移、滚轮缩放、方向键微移、Alt 拖复制和 F 预览。输入框、菜单和组合输入状态会被全局监听器排除。

### 合并到本地的边界

本地实现采用自己的颜色、间距和组件结构；只吸收快照历史、动态右键撤销/重做、持久化吸附开关和轻量图层定位。自适应网格、字节级历史裁剪、分组折叠和端口类型注册保留为后续演进点，避免在当前没有对应数据模型时伪造功能。
