## 技术裁定

- Ruling: 本地可验证的技术范围允许合并，外部未验收能力维持 PARTIAL — `REVIEW.md` 明确缺少真实 Provider 证据只阻断依赖它的结论，不能冻结其它本地工作；用户已授权分支合并 — 若判断错误，风险是接口行为仍需要外部验收，不能宣称完整真实能力。
- Ruling: 控件与图标采用最新四页 Figma 的 24/32/40 与 16/20/24 闭合轴 — 更新旧 44px composer/非闭合图标断言，同时保留触控区域不重叠及窄屏可达检查 — 若判断错误需调整具体组件视觉，不改变存储与服务行为。
- Ruling: 未连接 Codex 发送应显示连接失败并保留草稿；未配置直接生成禁止提交且提供模型设置入口 — 保留既有 Agent 故障契约，修复直接生成的提示被草稿更新清除 — 若判断错误会影响连接引导，故通过独立审查与手机实际交互检查。
- Ruling: 紧凑首页仍须有可达的批量与数据模式 — 复用 GenerationOptions 放入模型菜单，直接上传按钮保持单一动作，插件和伙伴从设置访问；未接入的平台额度继续明确 Prototype。删除原首页入口会导致既有批量任务能力不可操作。
- Ruling: 新版侧栏采用固定展开/收起宽度 — UI_RULES 的离散状态契约优先于旧可拖动侧栏；对话面板仍保留有边界的鼠标和键盘调整。旧侧栏拖动用例替换为两个实际宽度及焦点回归检查。
- Ruling: 桌面 --data-dir 同时隔离记忆；迁移只能在开启记忆后进行 — 启动不访问共享记忆，旧文件在锁内校验后迁移；损坏、并发和备份失败保持原件。
- Ruling: production preview 沿用仓库固定1423；被占用的development 1421保持原进程 — 两种模式分别记录实际bundle，不自动漂移开发端口 — 若判断错误，需补跑有可用端口的development验证，当前production/embedded身份仍可追溯。
- Ruling: 画布展开使用已有ReferenceStrip语义槽，紧凑态保留原外壳；textarea按上下锚点避开底部操作 — 实际动画中固定高度会重叠，静态高度通过不能代替动画检查 — 若判断错误，影响局限于展开输入几何，由短高与展开命中区回归保护。
- Ruling: 过时fixture和文案按当前规则维护，保留真实交互/边界断言 — 空项目不是演示项目，当前设置入口和控件数值由四页基线决定；69张历史生成图恢复到HEAD，新证据独立存放 — 若判断错误，风险是维护测试遗漏原交互，故通过全量回归与独立审查核对。
