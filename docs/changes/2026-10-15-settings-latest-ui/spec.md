## 入口与用户行为

侧栏设置和 `settings/providers`、`settings/mcp` 等现有深链接经 `App.tsx` 的设置 modal 进入 `SettingsPanel`，再进入各分区及模型接入列表/详情。实际浏览器 URL、模式、script 和 import 链由本次 verification 回读。

- 宽屏保留 1280/240/192 已注册几何和现有二/三栏；窄屏保留设置分类 → 接入方式 → 详情与返回/回焦路径，不恢复旧版布局。
- `vite.config.ts` 的 watch 忽略只针对本项目内部 `resolve('.worktrees')`，不能因当前 checkout 处于外层 `.worktrees` 而排除全部源码；保留其他 ignored 规则。最新布局回归须检查实际几何，避免误运行旧 UI。
- 长连接名、模型名、路径和错误文案在当前容器中换行或滚动；内容不横向溢出，不遮住保存、删除、返回或关闭。
- 关键保存与错误反馈在当前页面可读；提示不能拦截后续操作，不通过提升所有弹层层级掩盖问题。
- 异步状态复用当前操作所有者的 busy/取消契约；loading 不可重复提交，结束、取消或失败后恢复导航，迟到结果不覆盖新操作。
- 未配置、离线、读失败、保存失败和不支持能力显示真实状态与下一步，不把目录读取或 CLI 检测当模型生成成功。
- Escape、键盘 focus-visible、回焦、输入编辑和手机触控命中继续可用。

## 数据、兼容与权限

复用 Provider registry、系统凭据库与原保存事务；先检查所有调用者并在共享责任层处理保存风险。UI 布局不得改变协议字段、目标/连接 identity、credentialRef、深链接或存储 schema。保存失败不能清空原配置、把旧密钥误判为新密钥或报告假成功；只用隔离合成配置做破坏性故障注入。

API/OAuth/代理秘密继续只进系统凭据库或请求内存，不进入截图、localStorage、文档和日志。本次不新增网络请求、权限、外发数据或付费服务；普通布局/保存修复沿用现有 ADR，无新增公共契约时不新增 ADR。
