## 数据及算法

MaskRegion 用稳定 ID、逐行像素区间 runs 保存区域；矩形、笔刷与填充均转换为 runs，不保存屏幕坐标。编辑文档在来源节点保存，撤销重做共用一个历史。确认色块的编号按颜色单调分配（A–Z、27…），删除不复用编号。

Crop 按蒙版真实边界取得最小正方形，四边各扩原边长 5%，ceil(side/2)*2。先真实重叠合并，再反复合并相交裁剪正方形，直至不相交。尽量移到图内；图比正方形窄时采用边缘像素延展，坐标可逆。最终 <=3 个范围创建现有独立 task，>3 一个整图 task。档位 <=1000 为1K、<=2500为2K、其余4K；从模型已声明正方形尺寸选目标，没有目标则最高可用，没有尺寸则 omit size。

局部任务保存原图 assetId、区域 Mask、crop、groupId 和本轮要求，重启/重试沿用这些快照。native inpaint 明确支持时发送透明区为可编辑的 PNG mask；只有明确 edit 能力时允许原图+标注图编辑。未知局部能力禁用，普通整图旧兼容保留。标注图不替代原件，参考数包含标注图并复用现有限额。

有色块的 native 请求仍附带带编号的标注图，避免二值 union 丢失指令定位。显示和请求标注共享实线轮廓与标签绘制。无确认修改意见的色块不进入有效 Mask。

返回图片映射到 crop；明显比例不一致拒绝，保留原件。共享 compositor 对 Mask 内部距离羽化，Mask 外逐像素不动。组内已成功区域参与累计合成；每个候选另存原件，失败区域独立重试。没有可靠的语义几何偏移检测时允许对候选人工确认，不声称已能自动识别任意模型位移。

## UI、上下文与失败

原重绘弹层升级为 gallery 编辑视图：原图完整适配、悬浮可拖工具栏、浏览/框选/画笔/色块、原像素笔宽、滚轮指针缩放、空格拖动、双指缩放平移、复位。第二触点取消未提交笔迹；resize修正工具栏范围。使用原 Modal/ComposerTextarea/token；输入附件、@候选和确认标签保持紧凑，IME Enter 不发送。

灯箱延续原预览入口，相关图片横向列表/元信息/下载/重绘/重试/确认删除。放大或编辑时不处理切图手势。删除节点保留作为历史引用的归档原件，不破坏已提交任务；选中图片删除后选择相邻候选。

整图连续编辑保留当前源、最初提示词、最初参考、最近修改、本轮要求和新增参考，不无限拼接历史指令。生成候选有对应 task，可按原快照重新生成；原重试机制禁止 unknown 重复提交。取消、离线、超时、失效来源和迟到返回沿用原任务/持久化保护。

结构化请求总长度不超过原有 4000 字符边界；本轮要求和区域指令完整保留，初始/最近上下文分配剩余空间。必需指令本身过长时，在审批或创建裁剪原件之前提示拆分。蒙版尺寸上限 16384、总像素 6400 万、区域 200、区间 50 万，历史最多 40 份；笔刷按 scanline 胶囊截面计算，填充限制原图连通区域面积 35%。

Web 项目包收集 source/mask/历史参考；Desktop 包独立校验编辑字段并保留它们。已经发布后删除的图片候选在原生任务对账时不会重新加入画布。供应商缺少请求 ID 时省略可选字段，保持严格素材元数据校验。
