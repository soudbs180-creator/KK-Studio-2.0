## 用户原意与工程转译

保留成熟实现，补齐准确、稳定的局部重绘和连续编辑。三个工具只产生原图像素坐标的蒙版；共享合并、裁剪、模型能力检查、请求和合成。原件不可变，蒙版之外的像素必须保持原样。

## 验收

1. AC-1：框选、笔刷、色块使用同一 Mask；缩放/平移/复位/撤销重做不改变编辑位置，双指不误绘。
2. AC-2：最小正方形四边各扩 5%，向上偶数取整；反复合并相交发送范围；最多三块分开发送，超过三块整图发送。
3. AC-3：目标档位按 1000/2500 阈值选择且只传模型声明尺寸；原生 mask 优先，参考编辑需要明确能力及标注图。
4. AC-4：蒙版内羽化、尺寸映射、越界补齐；失败/取消保留原图和成功候选；可重试失败区域。
5. AC-5：色块稳定 ID/编号、结构化 @ 引用、空指令不发送；附件和原图角色区分，保留有界连续编辑上下文。
6. AC-6：现有图片预览扩展灯箱及重绘入口，候选比较/下载/删除；Desktop/Web 回归和可运行检查。

## 已知边界

FACT：主线仅有整图重绘表单、归档/任务/模型目录；节点画布的框选并非图片蒙版。图片色块/笔刷和原生蒙版传输缺失。其他 UI worktree 有未提交改动，本轮不接管。共享前端影响 Desktop/Web；Mobile 原生应用、真实付费模型及模型输出视觉质量需要独立验收，不以 fixture 代替。无生产发布、真实付费调用或用户数据删除授权。
