# 验收契约

- 同一已挂载画布接收 Agent 的已有节点移动、新节点指定位置、reference 连线新增/删除；DOM 与项目图一致。
- 位置和连线持久化到 IndexedDB；删除测试上下文恢复副本后重载仍一致。
- 原有节点内容、素材引用、其他连线保持；不调用生成服务。
- 用户新增节点、拖动、取消、撤销/重做不得被默认位置或无关外部快照回滚。
- 接收外部图在持久化 effect 之前完成；等值快照与回写不产生保存循环。
- 当前本地位置与外部位置都变化时保留尚未提交的本地交互，不静默覆盖。
- Desktop 原生文件/发布物与真实 Codex/Provider 验收与浏览器 fixture 证据分别记录，不互相替代。
