# Intent：三端独立版本与本地数据目标

- Task ID：TASK-VERSION-001
- 状态：READY
- 日期与提出者：2026-09-28，用户
- 请求来源：用户要求客户端 > 网页 > 手机的交付顺序、三端独立版本，当前统一 2.1.1；客户端可免登录或登录，网页/手机需登录，个人数据存在设备本地而非浏览器，网页采用本机伴随服务。
- 授权范围：建立版本管理与显示规则，并把新平台/账号/存储目标写入现行项目依据；不把尚未实现的账号、本机服务或 Mobile 标为已上线。

## 用户原意

用户不想在每次改动时手动指定版本号。大版本 `2` 代表完整产品代际，中间位 `1` 是较大功能阶段，末位按各端实际变更递增；`2.1.10` 是合法的两位补丁号。桌面优先交付，网页跟进，手机按网页能力裁剪和移动端优化。

## AI 工程转译

一个仓库保留三端独立版本源；桌面 Tauri 包、网页显示/NPM 包、尚未发布的 Mobile 元数据分别读取对应版本。提供确定性的 bump/check 命令，并在项目规则中要求 AI 根据本次实际受影响平台自动更新，不依赖用户每次提醒。将本机伴随服务/登录目标与当前 IndexedDB/演示账号的差距记入架构和账本。

## 边界

当前账号仅演示，Web 项目/素材仍在 IndexedDB，原生 Mobile 不存在；本次不会创建身份服务、支付、云同步或本机伴随服务，也不会迁移用户数据。正式安装包、Web 发布与 VPS 上传仍需各自验收。
