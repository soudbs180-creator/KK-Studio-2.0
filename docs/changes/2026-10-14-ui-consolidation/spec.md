## UI 与平台

1. 规则链仍是 UI_INDEX → tokens.css → 共享组件 → 页面 → 实际浏览器/桌面验证。用户本轮要求覆盖相冲突的旧默认蓝紫、收藏独立页面和灯箱喜欢位置；历史证据保留当时含义。
2. 默认强调色绿色；显式保存的其他颜色保持。普通主要动作可用中性白色；状态、危险操作按语义着色，不能把每个按钮涂成强调色。
3. 按钮使用现有24/32/40档位与语义间距；文字与图标居中；默认按内容扩展，在容器上限和超长内容时才省略，hover/title或其他无障碍描述保留完整名称。胶囊动作与方形圆角上传/IconButton 分开。
4. 文字输入过程去掉外侧明显描边/发光框；键盘 focus-visible 保留克制的可见提示，不取消键盘可用性。校验失败仍展示明确消息，不以红框作为唯一反馈。
5. 喜欢复用既有 likedIds；卡片顶部动作栏统一喜欢/标签入口。收藏保留原 favoriteIds，通过兼容“旧收藏”标签投影归入标签结果，不自动丢弃历史标记。
6. 喜欢/标签各自为固定大小可拖动面板，独立开关、位置、层级、键盘关闭；拖动把手不劫持内部按钮，拖动不平移画布；窗口变化后可重新找到面板。收藏旧深链映射标签入口。搜索独立查找项目/节点/归档资产并按类型、标签、来源过滤。
7. 标签用于分类；喜欢用于偏好；资源库用于归档原件、来源、查找和复用；存储用于实际位置、占用、缓存/备份与恢复；使用记录用于真实任务/输出/token/金额回执。这些不是同一个状态源。
8. Desktop 设置可用“分组导航 → 分类/列表 → 详情”三栏，低密度页只占二栏；窄屏网页保留完整内容。原生 Mobile 使用单屏分级导航/返回和触控布局，消费同一语义规则但不复制桌面几何。
