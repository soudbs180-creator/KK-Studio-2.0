# 验收约定

- 门禁以 Git 暂存或提交内容为准。工作树中稍后的修正须实际暂存才进入检查。
- 允许删除旧产物、清理已提交敏感内容、移动合法文件、提交模板和正常源文件。
- 检测禁止路径、已知凭证标记和 `src/` 新增或修改文件的相同 Git blob。输出类型与路径，敏感值及符合识别规则的文件名须隐藏。
- 安装使用现有 Git guards 入口，共享工作树使用同一份策略。第三方 pre-commit 原样保留，已有 pre-push 安装或升级照常执行。
- CI 在现有交付 job 以精确 base/head 检查新引入的每个提交。执行失败时门禁拒绝继续，产品及存储行为沿用当前版本。
