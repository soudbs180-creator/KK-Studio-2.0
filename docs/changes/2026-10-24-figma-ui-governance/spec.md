# Spec：治理范围与本地契约

## Figma

- 规范与命名：模型参数、输入更多、账号菜单、Agent 选择、参考媒体、任务搜索、灯箱重绘、编组信息/堆叠收纳、画布工具栏和资源筛选状态已在当前文件中补齐或校正。
- 交互语义：编组支持名称、边框颜色、信息/堆叠收纳、展开和解组；视频参考区分首帧/尾帧，音频使用紧凑图标浮层。

## 本地

- `CanvasGroup` 是独立持久实体，引用节点 ID 和资源包 ID，不冒充素材库记录。
- `ProjectCanvas.groups` 保持对旧 v1 快照的兼容；读取时校验、过滤失效成员，写入时保留名称、颜色、布局和收纳模式。
- 灯箱关联图最多展示 6 项，当前项居中，桌面端为左侧纵向列，窄屏回退为横向滚动列。
- 视频/音频参考保存 `kind` 与视频 `referenceFrame`，参考预览按媒体类型降级。
