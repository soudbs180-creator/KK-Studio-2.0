# 行为规格

## 数据

- `CreationProject` 是项目边界，拥有自己的提示词、模型、附件、画布节点、消息和任务。
- `CreationTask` 绑定一个项目和一次提交，状态为 queued、running、succeeded、failed、cancelled 或 offline。
- 项目快照保存到 `kk-studio-next:creation:v1`。内容仅是非敏感草稿和用户选中的本地素材；API Key 只在当前页面内存中保存。

## 控件

- 首页加号读取图片文件，限制图片类型、8MB 单文件和 4 张，显示缩略图并可删除。
- 首页模型按钮选择本次创作模型；“配置供应商”才进入全局连接设置。
- 首页模板把标题和描述完整放入提示词，分类会真实筛选卡片。
- 首页提交创建新项目并自动建立首个图片任务；工作台消息建立同项目的新任务。
- 工作台任务条区分运行、成功、失败、离线和取消；失败、离线、取消可重试，运行中可取消。
- provider 返回图片 URL 或 base64 时回填结果节点；没有连接或响应无结果则保留失败原因。
