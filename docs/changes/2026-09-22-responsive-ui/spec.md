# 三档响应式规格

用户请求授权范围内的 AI 技术决策。颜色继续用 DS 1.1，新增尺寸规则写入 DS 1.2，优先于历史窄屏说明。没有手机/平板 Figma Frame，本轮为依据现有资产的工程适配，不声称逐像素复刻移动稿。

| 档位 | CSS 视口宽度 | 导航与内容 |
| --- | --- | --- |
| 手机 | <768 | 56px 顶栏、64px 底部四项导航、抽屉项目列表；内容使用全宽；对话打开时占用内容面板 |
| 平板 | 768–1200 | 默认72px紧凑侧栏，展开为覆盖抽屉；对话宽400px并覆盖画布，不再缩成细条 |
| 电脑 | >1200 | 保留已确认桌面几何、291/70侧栏和470对话；原图标槽与语义色 |

共用业务和草稿，窗口跨档不重置项目/会话；桌面折叠偏好独立于临时抽屉。手机按安全区预留空间，页面采用dvh；抽屉、菜单、对话可重复开关、Escape回焦。对话覆盖时背景画布控件不接受点击/键盘焦点。

图标固定槽居中，保留原SVG比例；标签、图标、尾部操作不可分别压缩或绝对定位到容器外。手机主要点击目标44px，平板40px；小图标不等于小命中框。控件短标签不拆行；长项目名省略并提供完整名称；说明正文正常换行；工具行按明确分组排列，不以随机flex-wrap解决所有宽度。

验收：360/390手机、768/834/1024平板、1440/1920桌面，以及767/768、1200/1201跨界与横竖转换；首页、项目库、Skill、ComfyUI、画布、对话、设置/提示词弹窗同状态截图；图标中心、控件边界/可点击性、草稿和焦点保持；全量verify、fresh Tauri与独立预检。

桌面补充：移除整页1920×1080 letterbox缩放；字体、图标和点击区域保持CSS像素尺寸，通过弹性内容宽度响应实际窗口。1920参考几何仍验收，较窄电脑窗口不能以同比缩小作为适配。
