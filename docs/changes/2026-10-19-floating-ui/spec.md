# Spec：圆润控件与悬浮导航

- Task ID：TASK-UI-FLOATING-20261019
- 状态：READY
- 现行入口：[DESIGN.md](../../../DESIGN.md)；当前用户截图优先于历史固定 Figma 几何。

1. 以用户本轮纠正为准：撤销全局按钮边框、高亮和圆角覆盖。截图内首页模型/扩展触发按钮取消默认边框，仅沿用其交互反馈；分类、标签、菜单及其他按钮不新增统一描边。
2. 保留原有圆形、圆角矩形、胶囊、内容卡片及菜单的不同角色，不能把“不要尖角”解释为全局胶囊化。只修改明确标出的控件，键盘焦点、禁用语义和命中区保留。
3. 手机主导航四项等宽，整体水平居中、两侧与底部留白、浮于内容上，使用半透明表面、模糊和阴影。透明效果不可用时仍以实体表面保持可读，顶栏按钮定位不随底栏变动。
4. 导航、搜索、设置、更多与项目入口复用 UiIcon 内联矢量；公共名称及 aria 语义保留，未知名称不能静默替换为其他图标。
5. 1600/1601 宽度切换不裁切首页技能操作。底栏不遮住画布、编辑器和底部操作，触控目标至少 44px。
6. 新截图反馈：项目存储保护提示可关闭大卡片，保留紧凑“读取保护/保存失败 · 查看详情”入口。只用组件内临时展示状态；不解除读取/写入/执行保护，不丢内存草稿，不触发重读/保存/下载。状态、错误内容或恢复草稿变化后重新展开，刷新默认展开，原恢复操作完整保留。
