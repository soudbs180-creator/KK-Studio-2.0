# 规格
- 复用 KK 素材库、共享附件 UI、vendor/canvas-agent 的附件协议，不替换上游整体应用。
- Agent 草稿与直接 API 草稿隔离，按项目保存当前页面会话内的文字和附件；刷新前未发送 Agent 草稿与既有行为一致，暂不持久化。
- 明确选择本地 PNG/JPEG/WebP/GIF 或有归档原件的画布图片。最多 6 张、单张 8 MiB、编码请求附件合计 28 MiB；相同原件去重。无效、缺失、损坏、越限必须阻止整次发送，不可静默改成纯文本。
- 发送前冻结附件快照，从原件读取内容并验证尺寸。只把选定的图片发给当前 Agent，不抓取任意远程 URL。取消/项目或连接变化使旧读取失效；失败保留草稿，新输入不被旧成功清空。
- 消息留下图片名称与画布引用的可见记录；不在消息元数据放凭据或任意外部路径。
- canvas_select_nodes/select_nodes 支持单选、多选、清空；不存在的节点整条拒绝。canvas_set_viewport/set_viewport 接入现有变换与持久化，要求有限数值和 0.2–4 缩放。
- 操作要影响真实控件，快照含实际选择和视口；不改变已有取消、去重回执、权限、生成边界。
- Web production preview 和新 Tauri release 分别检查附件、草稿隔离、MCP 控制。真实 Codex 识图单独验收；fixture 不能代替真实识图，不声称图片编辑/生成已验收。
