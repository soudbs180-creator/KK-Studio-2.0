# Spec — TASK-PROV-001

- 无合格 BYOK 连接时首页保留草稿，不创建任务、不发送HTTP；对话保留草稿并提示具体原因。
- 已绑定任务不自动替换连接、地址或凭据；固定连接缺失、身份变化、冷却、隔离、禁用、满载、能力不符时拒绝。
- 审批不是连接授权快照；审批后及每个实际HTTP片段发送前重新读当前元数据。凭据和附件异步读取后的变化也必须生效。
- 同一JS运行实例中同步校验并占用槽位，仅实际占用者释放；拒绝不能递减其他任务计数。持久TaskHost/跨进程分布式租约属T5。
- 占用记录带不透明的本地 lease identity；连接被移除后用相同 ID 重建时，旧任务不能释放新连接的槽位。跨重启的孤儿槽位回收仍由 T5 TaskHost 负责。
- 用户显式重试/恢复可尝试原连接的degraded状态；不将该尝试伪装为health成功，不解除cooldown/quarantined/disabled。成功响应才按未被新失败替代的health状态恢复。
- 401/403隔离；429遵守Retry-After不能因15分钟上限提前发送；网络/5xx可恢复但不自动换账户。
- 延续现有审批、取消、离线、部分结果、草稿及凭据保密契约；不新增UI布局，错误文字属于工程补充。
- 本地main必须包含源修复并复验；无remote不阻塞本地合并，不声称远端PR/保护/付费服务验收。
