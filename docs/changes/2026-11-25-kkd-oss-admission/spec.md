# 准入契约

- `src/integrations/oss/<组件>` 与 `vendor/<组件>` 各需一条显式 vendored 或 adapter 记录。纯研究参考沿用 `inspired` 类型。
- 新接入绑定 HTTPS 仓库、完整提交、版本、已识别的 SPDX 许可文本、依赖、输入、实现及运行收据。Git 跟踪和未被忽略的组件文件均需包含在哈希锁定集合中。
- 收据绑定来源与文件摘要，记录原项目和候选运行、相同输入及各自输出。实际原始运行、许可范围与行为覆盖由审查人员核对。
- 三个指定历史组件只在与官方基线目录一致时沿用历史状态。变更后执行当前准入检查。
