# 新版 Figma 四页 UI 治理基线

## 基线与裁决

本次改动只以 Figma 文件 `0nU0A7pq6eyjwfwm1TtWkO` 的四个治理页面为设计和业务基线：

| 页面 | 节点 | 负责内容 |
| --- | --- | --- |
| 01 业务规则与状态矩阵 | `505:13071` | 实体、数据流、事务约束、11 个业务状态 |
| 02 审查问题与修复记录 | `505:13430` | 缺陷分级、修复状态、术语和审查闭环 |
| 03 UI 基础规范 | `505:13731` | 字体、间距、控件、图标、反馈和对齐 |
| 04 页面类型模板配置 | `505:14180` | 五种页面模板、选型和嵌套规则 |

旧版页面草稿、旧组件局部 CSS、历史 A1–A9 页面类型和旧字号表不再拥有
裁决权。代码中的兼容别名只能保持已有运行态，不得产生新的视觉规则。

## 业务规则

实体链路固定为：

`项目 → 画布 → 资产 → 会话 → 任务 → 模型 → 账户`

每个生成入口都必须经过：

`输入/上传 → 模型与参数 → 预校验 → 冻结积分 → 创建任务 → 生成结果 → 写入资产 → 收藏/喜欢`

1. 预校验未通过时不能冻结积分。
2. 创建任务失败必须立即释放冻结。
3. 成功结果先写入资产，再允许收藏或喜欢。
4. `favorite` 与 `liked` 是两个互不替代的布尔值。
5. 本地导入如果未同步账户，页面必须明确标注本地范围。

### 11 个状态

| 状态 | 可用操作 | 禁用操作 | 必须反馈 |
| --- | --- | --- | --- |
| `idle` | 输入、上传、选模型 | 提交 | 占位提示 |
| `editing` | 编辑、上传、清空 | 未通过校验前提交 | 本地草稿保存 |
| `validation-error` | 修改、打开设置 | 提交 | 字段原因、影响、下一步 |
| `ready` | 提交、保存草稿 | — | 唯一主操作 |
| `queued` | 查看任务、取消 | 重复提交 | 排队位置或预计时间 |
| `running` | 查看进度、取消 | 重复提交、修改任务参数 | 持久进度 |
| `success` | 查看、下载、重建、收藏 | 取消 | 非阻塞成功反馈 |
| `failure` | 重试、查看原因、反馈 | 下载空结果 | 原因、影响、恢复路径 |
| `cancelled` | 重新提交、查看记录 | 继续旧任务 | 积分释放结果 |
| `offline` | 编辑本地内容、查看缓存 | 提交、云同步 | 持久状态栏 |
| `service-unconfigured` | 打开设置、查看指南 | 提交、测试生成 | 缺少能力和入口 |

状态判断集中在 `src/domain/uiGovernance.ts`。首页、画布、对话的按钮、键盘
提交和菜单命令必须调用同一谓词；禁用态必须提供可读原因。

## UI 基础规范

- 间距基准为 4px；产品文字不小于 12px。
- 文字样式固定为 `12/16`、`14/20`、`14/20/600`、`16/24/600`、
  `20/28/700`、`26/32/700`。
- 控件高度只有 24、32、40；图标图形只有 16、20、24；最小命中区为 24。
- 标准按钮四族为 Primary、Secondary、Tertiary、Danger；同屏只能有一个
  Primary；按钮状态必须覆盖 default、hover、pressed、focus、loading、
  success、failure、disabled。
- 标准按钮圆角为 8；菜单为 10；面板和卡片外壳使用已注册的 20；药丸使用
  999。组件不得在页面级另造圆角。
- 紫色只用于主操作、焦点环和关键状态；失败反馈必须同时说明原因、影响和
  下一步；关键结果不能只依赖 toast。
- 单行文字使用省略号，多行说明最多三行；图标先进入固定槽位再与文字对齐。

实现入口：`src/styles/tokens.css` 是语义 token 源，`src/styles/ui-tokens.css`
只做兼容映射，`src/styles/ui-governance.css` 提供共享组件状态。

## 页面模板

运行时只有 `list`、`grid`、`detail`、`timeline`、`gallery` 五种一级模板，
工作展示默认 `grid`。混合页只能有一个一级模板，其他模板只能作为嵌套区域；
`list`、`grid`、`timeline` 不得在同一层并列为多个主布局。

注册表和选型函数位于 `src/domain/pageTemplates.ts`，机器可读配置位于
`src/styles/archetypes.json`，共享布局类位于 `src/styles/page-templates.css`。
