# Spec

## 结果

以 [`docs/governance/UNIFIED-PROJECT-RULES.md`](../../governance/UNIFIED-PROJECT-RULES.md) 作为跨主题规范入口：根入口保留硬边界和协作契约，专项文档只承载领域细节，机器源/生成视图/历史证据分层。

## 必须覆盖

1. 现状来源清单和事实状态；
2. 仓库、容器、worktree、源码、测试、文档、生成物边界；
3. 文件、目录、分支、Task ID、ADR、feature、change package 和中英文命名；
4. 接收、登记、隔离、设计、实现、验证、审查、合入、发布、回滚全流程；
5. 23 条重复/矛盾/过时规则的“原规则 → 新规则”裁决；
6. 新任务/规则变更、废弃/归档/兼容、版本和同步门禁。

## 约束

当前 checkout 非干净；只新增本规范、索引入口和本次 change package，不重置、清理或覆盖并发改动。Hosted、Provider、Tauri、发布和用户验收不由本地文档检查推导。
