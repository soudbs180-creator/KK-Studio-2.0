# 真实项目侧栏整合 Spec

## 数据与操作

`App` 中的 `creation.projects` 和 `activeProjectId` 是项目唯一来源。侧栏行及搜索结果都以其 ID、名称和内容生成；没有项目就没有项目行或演示文件夹。创建调用现有空白项目流程；打开先写入 activeProjectId，再进入画布；改名更新同一项目并持久化；删除经明确确认，进行中的任务或存储不可写时禁用。

侧栏文件夹、拖放、文件夹命名和置顶保留 `TASK-UI-009` 的会话级状态，成员只记录真实项目 ID。刷新后项目回到未分组，置顶恢复原顺序，用户可在控件说明看到此边界。排序可选快照原有顺序、最近更新、任务状态优先，名称必须描述实际计算依据。项目行缩略图从实际项目内容判断：可显示的生成图片优先；纯文案使用聊天图标；其他项目使用按 ID 稳定选取的纯色。

## 验收与失败边界

- 空库、读取失败和新建后的界面不出现固定演示项目；读取失败不能删除或覆盖原件。
- 多项目同名也按 ID 打开正确项目；改名取消保留旧名，成功后刷新仍可见。
- 删除必须确认；取消、活动任务、不可写存储不改变快照。删除当前项目后回项目库空态或其余项目列表。
- 文件夹移动不修改持久项目，刷新回到未分组；此状态在 UI 中可理解。
- 390/768/1440/1920 视口无溢出，键盘可展开、打开和操作项目。

本轮不引入持久文件夹 schema。后续要持久分组需同时更新 Web/原生快照、项目包验证与迁移，并另写 ADR。
