# UI / 功能接线核对

2026-09-22，当前融合候选 cf344dd + dirty snapshot；核对功能登记册、App 实际 import、组件事件与服务调用。任务完成与外部能力验收分别记录。

| 能力 | 核对出的 UI 问题 / 当前边界 | 本批处理 |
| --- | --- | --- |
| 图片任务 / FEAT-002、003 | 首页/对话经统一图片任务；项目模型与 Agent 账号模型不同 | 明确图片通道；原供应商、附件、批量与审批链保留 |
| 文本节点 / FEAT-008 | “剧本/策划案”按钮只改状态文案，未改变输入；真实文本任务仍被标“前端草稿” | 选择方式写入可见指令；切换仅替换已知前缀并保留正文；自由写作/字符上限处理；本地草稿标识 |
| 本地 Agent / FEAT-009、012 | 连接后仍显示图片附件/模型/旧审批；connecting/error prop 不传；断线落回图片；忙碌状态被回显提前清空；停止/审批失败被吞 | 独立通道/草稿/权限、全状态传递、错误反馈与重试；迟到连接不复活；同端点重连保留消息；Token 密码字段及会话内存；命名 SSE/hello、注册顺序与首次准备入口；warning/审批队列及迟到回执保护 |
| 画布插件 / FEAT-013 | 菜单硬编码“没有插件”，管理入口指向 MCP；实际 4 个插件已加载 | 读取 pluginStore；命名“画布插件”；进入 settings/plugins；MCP 单独入口；安装与启停仍走现有 loader |
| 提示词 / FEAT-029 | promptLibrary 已有解析/缓存/检索但零 UI 调用 | 新面板与首页/图片对话/文件菜单入口；主动加载、缓存、搜索、分页、预览、取消、失败、文字追加到草稿 |
| 音频 / FEAT-007 | 文案按钮错误地出现在音频卡；TTS 函数没有统一任务/资产提交链 | 去掉文案模式，标固定演示与参数边界；真实 TTS 提交属于 BACKEND-MEDIA-001 |
| 视频 / FEAT-006、025 | 固定素材演示；比例/时长已有“不发送”说明 | 保留明确演示及取消；不把参数展示认定为真实生成 |
| ComfyUI / FEAT-004、005 | 工作流文件管理可用；adapter/原生命令未接任务链；设置显示未连接 | 保留导入与文件管理；出图缺工作流绑定、任务宿主和资产回执，T6 单独实施 |
| WebDAV / FEAT-019 | 只有 manifest/文件原语，当前工程项目包、原生资产引用与冲突策略未映射 | 不暴露误导性的“同步完成”；BACKEND-PLATFORM 继续负责备份格式/冲突/恢复/凭据接线 |
| 代理 / FEAT-021 | 信息卡声称“已接入”并让用户填不存在的全局配置 | 明确独立进程、支持 localProxyUrl 的调用范围，未全局生效；一键启停未实现 |
| Skill / FEAT-011 | 本地启用、编辑、保存与草稿应用已有真实入口 | 保留共享组件与既有回归；云端目录继续明确演示 |
| 账号/积分/记忆 / FEAT-017、018、020 | 未接后端，当前控件禁用且有原因 | 保留；不移除诚实的 Prototype 标识 |
| 项目/素材/任务工作台 / FEAT-014、015、016 | 本地持久化/工作台入口已有；外部分享/账单标 Prototype | 保留真实路径与审批，不把本批 UI 验证当 T5/发布验收 |
| 设置与平台 / FEAT-022、026 | Desktop 也显示“前端预览/当前浏览器/前端原型”；版本可读却显示不可用 | 平台由 Tauri 运行环境判定；版本读 package.json；更新服务仍禁用 |
| 导航/语音/画布 / FEAT-001、010、023 | 已有交互；新增入口不能破坏 Escape、焦点、输入与布局 | 纳入原全量回归与新增面板窄屏检查 |
| Gateway/Astra/Mobile / FEAT-024、027、028 | 独立后端/计划能力，当前无可直接接成完整产品的 UI 契约 | 保留相应任务，不扩大为新产品/权限/部署 |

新界面为 DS1.1 工程补充，不宣称缺失 Figma Frame 的逐像素还原。受控 HTTP/SSE 与公开目录 fixture 证明 UI 协议处理，不证明真实 CLI、账号、远端目录或付费 Provider 可用。
