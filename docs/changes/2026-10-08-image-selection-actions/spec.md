# Spec：图片选择动作与规则

- Task：TASK-UI-011；技术方案 READY；2026-10-08。
- [Intent](intent.md) · [Plan](plan.md)
- 图片卡片单击/键盘选择后，上方显示唯一动作栏；未选中时不显示，图片内部不保留重绘/放大动作层。
- 参考图与生成/导入结果图片复用动作栏。预览、重绘、比较以及已有结果的收藏/删除使用现有真实实现；不存在的裁剪/高清/多视角功能不伪装可用。
- 共享工具栏通过现有语义 token/按钮/UiIcon；标准命中高度 32，文字不低于 12，画布缩放不缩小工具命中区。跟随拖动/缩放/平移，并在可视工作区边界内保持可达，不覆盖图片内容、画布 HUD 和会话区。
- 单击图片选择，双击或工具栏打开预览；按钮不触发拖动/丢失选择。Escape、点击空白和切换卡片正确关闭；弹层关闭后恢复焦点。
- 重绘继续经过现有图片命令/模型/能力/原件/审批门禁，生成中防重复、取消保留未知受理语义。无模型时显示可读原因和设置入口。
- 结果收藏/删除/比较、原件身份、来源与项目持久化不改变。图片之外的音频/视频/文案保持各自既有行为。
- UI_RULES 唯一承载本轮新增的选择动作规则；不新增重复规范文件。新增页面审计记录实际 URL/mode/entry/source/import、computed geometry 和截图；Web 与 Desktop 分别复验。
- 影响 Web/Desktop，源码 patch 按集成后的实际版本自动递增；Mobile 无原生产物，不冒充原生验收。无新依赖、存储 schema 或付费外部调用。

AC：未选中不显示/选择显示上方且仅一个/安全动作仍可用/窄屏缩放拖动可达/页面规则核对/全量回归构建/独立精确 SHA 审查与当前托管门禁。
