# Spec

## 产品规则

- KK Agent 默认使用 Codex；显式选择直接生成才走已有图片会话。Agent 不可用时保留草稿和错误，不默默转成收费生成。
- Codex 模型来自服务端 model/list，与项目图片模型独立。使用官方执行器已有登录；不向 Agent 提供 Provider API Key。
- 首批能力为画布状态、节点增删改/连线、图片与文本任务提交和状态查询。视频、音频、尚未实现的工具明确拒绝。
- 本地连接 Token 仅保留内存，经请求头发送；清除旧 localStorage Token。连接失败和流中断不能显示已就绪。

## 生命周期

discover → 建立 SSE 并收到 hello → 核对当前项目线程归属 → activate → 同步项目快照 → 读取/恢复已登记线程（首次空线程使用 ID/revision 条件准备）→ 读取历史/模型 → ready。连续发送、切换 Codex 模型、重连沿用同一线程；只有用户明确点击“新建 Agent 会话”才调用 threads/new。其他项目正在运行的线程不得接管，旧服务不支持安全 prepare 时明确报错。

每轮发送前同步快照并确认项目仍一致。切换项目后，旧线程工具不能写入新项目。停止、审批、断线、401、过期会话均给真实状态。

## KK 工具

画布操作提交到 KK 领域层，纯修改/连线也要保存。组合操作先落地新增节点再提交生成。每个生成操作得到任务身份或明确错误；工具重投递不会重复提交。

生成复用 prepareImageTask / appendImageTask / executeTask 与原有持久化、审批、凭据、参考素材规则。返回受理任务不等于生成完成。不存在、未配置、演示视频/音频不能返回成功。

## 验收

1. 不新增 OpenAI API Key，从 KK 输入框取得真实 Codex 回复。
2. Agent 新建、修改并连线节点，刷新后仍存在。
3. Agent 提示词驱动已配置图片 Provider，受控 Provider 记录真实 HTTP 请求、返回图片并落入画布；真实付费供应商单列外部边界。
4. 流中断、取消、错误、重连、项目切换与工具重复交付均有回归。
5. 完整 npm verify、features 门禁通过；浏览器记录当前 production bundle。未改变 Rust 本轮不宣称 Tauri 一键启停完成。

## 本轮追加：账号、模型目录与参数

用户确认先按现有项目已配置供应商适配。对话保留默认 Codex，具体模型选择明确绑定账号来源；API 模型必须绑定 connectionId，重名模型不能混用凭据。共享菜单提供 来源 → 供应商 → 模型、返回、记忆最后页面、全部模型模式与当前页置顶。谷歌/豆包/WorkBuddy 尚无可调用适配器时显示禁用原因。

额度读取官方 app-server account/rateLimits/read，展示共享窗口与重置时间；未知不等于 0。读取到当前共享 Codex 额度用完时阻止新回合。额外模型额度仅提示，不误阻止其他模型。

API 目录刷新沿用现有 OpenAI 兼容 /models；仅持久化非敏感模型信息。能力有明确返回时采纳，缺少时允许用户按供应商文档声明。图片卡片仅显示明确尺寸/比例，未声明使用供应商默认值；新接口协议不冒充已适配。

Codex 内置生图如当前登录与执行器支持，走内置工具，不要求额外 API Key；输出须进入 KK 自有素材仓库并真实显示。网页登录适配器、并发浏览器任务与桌面进程托管另立待办，不能用可选菜单替代接入验收。

## 连续对话与型号参数补充

- 一个项目窗口的连续对话保留同一个 Codex 线程；新建是显式动作。API 与 Agent 草稿独立，迟到发送不能清除后续编辑或其他项目草稿。
- 同一 API 连接内按基础模型名分组，识别末尾 1K/2K/4K/8K/Low/Medium/High；版本、日期、命名空间保留。厂商特殊命名可按其文档填写分组名称、型号参数名称和搜索别名。
- 参数选择只列目录中实际存在的完整型号 ID。例如选 4K · High 对应原始 foo-4k-high，不发送删掉后缀的 foo，也不拼出不存在的组合。命名后缀是路由线索，不自动生成 quality、resolution 等请求字段。
- 搜索模型名、原始 ID、厂商名、别名、后缀和明确尺寸/比例。支持全角字符、大小写、乘号、模糊输入、有限英文拼写纠错，显示“可能匹配”；数字版本、尺寸与比例不纠错、不自动更换选择、不自动提交。
- 只有当前协议明确支持的请求参数可以发送。参见 provider-research.md；Gemini/DashScope/OpenRouter 原生协议没有被通用 /models 和 /images/generations 自动适配。
