# 已批准需求及边界

来源为用户本聊天批准的完整方案；以下是实施与验收索引，未列为完成的条目仍属开放范围。

| 编号 | 必须达到的行为 |
| --- | --- |
| BASE | 从当前主线核对旧候选，保留来源、失败证据、凭据引用、ID、存储键及旧链接；隔离运行资源和测试产物。 |
| UI | 设置分为设置（通用、个人主页、套餐与积分、快捷键）、功能（记忆、模型接入、扩展、网络）、数据与安全（数据管理、安全中心）；用量并入套餐，本地服务并入模型接入。统一 DESIGN、tokens 和共享组件；选中状态清晰；弹层不越界；连续缩放保留状态；用户消息右、助手左；去除重复控件。 |
| MODEL | 四渠道：中转 API、登录账号、官方 API、本地；选择器依次渠道、搜索筛选、模型。真实相同版本跨中转合并，按优先级绑定实际执行渠道，未知状态禁止自动换渠道重复生成。卡片单选，主 Agent 单选默认 Codex 且工具能力已验证，Agent 调用模型按聊天多选授权。发现默认勾选目录但不得扩大已有聊天调用授权。参数跟随执行模型及操作，默认推荐，切换保留各模型参数。 |
| API | 必要字段→添加并获取模型；先保存凭据和配置，再发现，失败保留，可重试手填。12AI 文本、图片、视频按真实协议分别实现并归档。 |
| AGENT | 发送、执行中暂停、正在暂停、已暂停继续、正在继续统一圆形键，40px/20px，触屏命中44px。真实确认后改变状态；草稿不被继续发送。同逻辑任务检查点、稳定步骤与幂等回执；已受理媒体继续查询归档；同线程后续轮次承接 Codex 中断，禁止伪装原推理恢复或重提任务。KK 自有 Codex 宿主、健康检查、同线程重连；桌面专属能力明确依赖。 |
| LOCAL | Qwen 包检测 GGUF/llama.cpp 后由画布启动普通对话；已有 llama.cpp/LM Studio/Ollama 只连接；ComfyUI 检查环境、权重、节点、工作流并接通 Flux/H3 提交、进度、结果、归档、恢复。检测只读，不运行、不生成、不下载，默认无 Key，能力依实装，不能误杀外部服务或调用收费托管 H3。 |
| PROJECT | 项目库和侧栏共用打开、改名、分组、垃圾箱、恢复；手动名称不被自动命名覆盖。分组持久化，删组只解除归属。项目多聊天，共享画布和素材，各自上下文、草稿、Agent、授权。聊天作品入库后主动添加画布；画布作品回填原卡。写入失败、并发冲突及未完成任务明确显示。 |
| TEMP | 临时聊天无记录、无记忆读写；新增输入暂存到任务结束；输出入素材库，仅文件和必要元数据，无提示词、摘要、提示词哈希、参考关联。已有原件不删除，正文不能进入日志、恢复和备份。 |
| REF | @ 引用真实文件/图片/素材，项目优先可切全库，明确选择电脑文件；预览移除失效检查，不能悄悄变纯文本。/ 调用已启用 Skill/插件/MCP，选择不发送，真实参数、权限和结果；授权按项目范围记住及撤销，新增权限才确认，跨设备不恢复设备权限。 |
| MEDIA | 所有入口共享目标模型媒体准备流程；图片从原件生成符合格式、透明度、方向、单体和总请求预算的副本，自动处理大图、内存有界，切模型不重复压缩副本。动画对静态模型选帧。视频输入超时长先选段，再按需确认压缩；不擅自拆段、变速、截断或丢音轨；真实视频修改，按供应商原生上传能力，不借云备份作图床。 |
| REPO | Desktop/Web 同机完整共仓库（项目、聊天、画布、索引、原件），统一格式、目录身份、跨进程锁、版本检查及回执，冲突保留草稿。Web 首次显式授权，不由登录扩大权限；关窗口但网页/任务使用时存储服务后台存活。断连离线禁止共享写入及隐式第二份数据。独立 Web 本地模式显式导入；生成原件默认授权本地目录。目录更改仅后续内容，旧目录登记，任务保存目的地冻结。数据管理分别显示安装、项目、生成、下载、磁盘缓存、内存。 |
| TRASH | 项目软删除完整恢复；删画布卡的作品进入素材垃圾箱，正常聊天作品不误删。保留步数默认20可设5–100；删除恢复跨重启，普通撤销栈仅会话。原件仅手动清理且超保留、无全部有效引用；离线/索引不可信禁止。引用含聊天草稿、编辑原图蒙版、撤销重做、任务及待归档。缓存单列。丢失、已清理区分，用户选目录有界扫描/fullSHA一致修复原身份；不同内容新身份且仅替换指定引用。 |
| WINDOW | 重复启动唤起原实例，单实例先于恢复；文件菜单新窗口/新聊天/临时聊天，新窗口共享宿主仓库但草稿独立；编辑撤销重做剪切复制粘贴全选复用快捷键，复制失败不剪切。最后窗口有任务才询问后台或退出，网页仓库租约保留必要服务。 |
| AUTH | 两端免登录本地使用；登录不上传产品数据。邮箱验证注册、同密码登录、成熟认证及客户端加密协议；不拼接标识生成密钥。客户端系统浏览器 kkai.plus 登录，一次性 code+PKCE+事务校验回跳原窗口，设备公钥封装密钥，秘密不进 URL。新设备同密码解锁，无恢复码；丢密码无解锁设备时不能解开旧密文，保留密文与本地原件。Desktop 系统凭据库，Web 加密持久保存。 |
| SITE | Cloudflare 风险挑战保护网页，登录注册验证码防滥用；API 禁止 HTML 挑战，敏感响应不公共缓存，源站防绕过。Web 版本展示真实客户端下载；Desktop 更新对应安装版本。 |
| SYNC | 只在网络设置手动同步，默认不上传、不监听。KK 仅所选渠道、独立密钥、偏好、加密云索引；用户 Cloudinary/WebDAV/S3 存完整加密项目/组包；本地保留主副本。客户端加解密全部敏感元数据，秘密不进项目包，会话/设备权限/临时内容不备份。冻结快照、流式加密分卷按真实配额、全部分卷完成→清单→CAS索引；恢复验证解密暂存再发布，冲突副本，不重提旧任务；未含原件明确不完整。首版云历史不自动清理，本地清理不删云。 |

接口沿用现有配置、快照、任务队列与宿主协议，扩展实际执行绑定、逻辑任务检查点、多聊天/分组/垃圾箱、目录授权和加密清单，不另建第二套系统。

验收覆盖首页、聊天、画布、项目库、素材库、编辑器、设置，以及保存、取消、离线、重开、恢复。真实生成、真机 Native、共享仓库并发、三个云端恢复、部署与托管 CI 均需独立证据。测试 mock 不可升级为 REAL。
