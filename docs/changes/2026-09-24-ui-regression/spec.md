## 用户行为与入口

### 2026-09-25 用户 Figma 与浏览器批注补充

- 以 `docs/DESIGN-SYSTEM.md` 的四节点补充为先行尺寸/状态规则。首页默认输入采用桌面652×170、手机306×170静态目标；动态附件、较大字阶和44px触屏目标可使高度增长。模型弹层227×318、画布节点编辑器590×237分别复用既有业务组件。
- 首页移除单独的“提示词库”按钮；空提示词提交应聚焦输入而不生成页面下方“先写下一句创意”状态行。保存、连接、取消等实际错误/结果仍有可访问反馈。
- 搜索分类改为底部分割线上的移动选中指示，顶端短横线不承担分类高亮。横向滚动和键盘切换应同步。
- 对话打开后不因外部点击/画布操作关闭；再次点击明确切换按钮或面板关闭按钮才收起。电脑/平板开关、侧栏折叠、任务、缩放、整理保持顶部同一水平中心线；开关展开前后位置一致。
- 窄屏画布底栏按实际按钮占用收紧宽度，无大片无作用尾部区域；电脑保留既定294×50参考几何。
- 首页模型弹层列出实际保存且声明图片用途的 BYOK 模型；选择时连同连接 ID 一并写入草稿，禁用或隔离连接不允许选择。同名模型必须保留账号身份，列表不伪造设计图中的静态行。

### 2026-09-25 全页面类型核对补充

- 按 `UI_ARCHETYPES.md` 的页面类型核对开始创作、项目库、Skill、ComfyUI、资产管理、提示词库、十类设置、画布、任务与搜索；记录桌面/手机默认状态的矩形和截图，不以“无整页溢出”替代控件合规。
- 资产管理归 A1 画廊，统一列宽、间距、卡片与缩略图圆角、元信息和筛选控件档位；提示词库用 A2 条目卡 + A4 预览，空态有单一明确加载入口。
- 新 UI 规则与运行 token 冲突时，保持已在 Figma/运行态确认的 291px 侧栏与 40px 顶栏；候选 `tokens.css` 不导入直到其与现行变量及在线 Ardot 完成回读。

- 首页创作输入区的插件、Skill、伙伴各有清楚名称；插件管理进入扩展页插件标签，伙伴进入 Agent 连接标签，模型配置进入模型接入页。
- 设置分类按现行页面分组。扩展页的插件、技能、伙伴标签支持点击及 Left/Right/Home/End，选中态与内容一致。
- 桌面侧栏和对话面板可拖动调整，保持画布最低可用宽度；分隔条可键盘调整、回到默认和端点。平板/手机隐藏此桌面操作。
- 手机底部导航保留 ComfyUI 工作流；首页工具组可分行但不溢出。手机扩展标签单行且触屏命中不低于44px。画布菜单、对话层、设置内容支持滚动、Escape 与回焦。
- 新建项目为空白；无项目时项目库显示真实空态，不出现可点击的假项目卡。演示画布仍可从工作流入口查看。Agent 测试使用显式真实项目 fixture，避免把演示状态冒认为新项目状态。
- API Key 显示切换保留明确标签和独立按钮，不把密钥写入测试日志或持久化。

## 架构、数据与权限

- 保留 React/Tauri 现有 `App → SettingsPanel/Canvas/ConversationPanel` 组件链，不引入新依赖或第二套设计系统。
- 面板宽度由当前窗口内的 CSS 变量控制，窗口尺寸变化时限制可用画布宽度；不改变项目/素材或 Provider 凭据结构。
- Provider 密钥仍按 Web 请求内存与 Desktop 凭据库契约；显示切换只改变输入类型。
- 扩展页展示现有 MCP、Skill registry、本地 Agent 连接。WorkBuddy、豆包账号适配与外部授权尚未由此实现。

## 生命周期与恢复

- 使用任务 worktree 构建全新 Web dist；桌面需重新打包运行。
- 无数据迁移；界面宽度可重置。原工程 dirty 文件和用户本地数据保持。
- 出现保存、断线或不可用时沿用既有产品错误状态，不增加假成功提示。
- 回滚为仅撤销本分支 diff；不移动主线或覆盖根工作区。

## 风险和决策

- 旧浏览器断言含旧设置分类名、未构建插件时的菜单数量和新项目示范节点假设；逐项按当前产品语义和源代码修正，不隐藏真实失败。
- 原根目录的并行 UI/Agent 改动未合并，不能把本 worktree 的通过直接描述为当前桌面软件已经更新。
- 真正的外部厂商接管、共享记忆、额度与智能调度仍需独立服务契约和真实登录验证。
