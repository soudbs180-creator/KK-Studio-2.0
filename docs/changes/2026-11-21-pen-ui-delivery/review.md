## 工作台设置候选独立初审

以 aa56c64b 为基线。需求和规范两路独立初审分别检查交互和代码。发现的 问题和候选修订如下。

- 画布连线及浮层可穿透新宿主。画布保持原尺寸、整层隐藏且 inert；喜欢/标签保持原挂载，关闭设置后恢复，画布撤销/重做在设置期间有禁用原因。
- 缩屏、路由和加载完成时可能失去焦点。复用隐藏控件焦点恢复，设置触发器在紧凑时提供可见回退。
- 连接事务期间可经侧栏更换项目或打开另一面板。应用面板路由与侧栏回收入口均已补保护。
- 设置工作台使用具名非模态 dialog 语义，既有首页与其他非画布入口继续用原生模态弹窗。
