## 工作台设置与会话折叠

- Pen hgib1 的设置内容区与 C5yCOp 会话是并列工作台区域。沿用活跃分类、滚动、待保存草稿和稳定返回焦点。窄屏内容区独占时保持已挂载设置和会话状态。
- 非画布设置继续沿用弹窗入口。宽屏会话为可访问的相邻区域。画布隐藏期间不可获得指针或键盘交互，恢复时使用原实例。
- 凭据提交挂起期间禁止切换设置分类、项目、快捷键面板和关闭设置。复用已有凭据事务。
- 高级会话操作适用 d7z7Ci 的描边规则。rD3yd 表示设计中的会话设置状态，具体操作及可用性沿用本地业务行为。

- 新入口打开时，只有宽屏画布且当前没有原生对话框的情况进入并列设置。窄屏打开和重绘等原生对话框内部入口保持模态，并在本次打开期间保持同一宿主。宽屏打开后再缩窗时同一表单继续可用。
- 设置打开时暂停被覆盖画布的视口测量和自动缩放。关闭后按当前工作台布局测量，避免用并列会话的内部坐标覆盖画布状态。
