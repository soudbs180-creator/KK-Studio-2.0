# 版本一致性与跨环境新鲜度

## 用户目标

解决本地启动使用最新源码而其他环境继续打开旧 worktree、旧快捷方式或旧工件的问题，并把产品版本、依赖 lock、构建缓存、时间戳、新鲜度检查和发布回执纳入同一套可验证规则。

## 范围

- 保留 `config/platform-versions.json` 作为唯一产品版本源。
- 增加根与嵌套 package lock、Tauri 依赖和活动源码版本硬编码的审计。
- 把版本门禁接入 lint 与 Windows CI。
- 明确任务分支、PR、合并 SHA、不可变工件和安装后回读的流程。

## 边界

本任务不把本地构建当成远端发布，不自动上传工件、不修改远端保护规则，也不把供应商/Agent/插件自身版本改成 KK Studio 产品版本。
