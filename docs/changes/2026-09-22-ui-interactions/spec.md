# TASK-UI-006 交互修复契约

1. 左上角项目名/保存/生成状态与任务入口统一分配空间，在桌面、窄屏、侧栏/对话折叠组合及长文本下互不覆盖；任务和重试/取消仍可操作。
2. 画布20%–400%缩放范围内背景点/网格保持可辨识、适度密度，与平移一致；保留100%当前页面相位和Design System颜色，不能通过消除点阵来隐藏问题。
3. 项目分组与侧栏折叠、画布节点/提示词与聊天折叠，不丢已有草稿或界面状态；折叠后的隐藏弹层不能继续抢焦点/处理Escape。
4. 同一功能按钮重复点击可关闭其弹层。覆盖任务、添加资源、工具、缩放、小地图、项目/账号、TopBar及设置/提示词等实际入口；Escape、外点、切换入口、模态交接和焦点回归符合现有分层规则。
5. 模态内部的编辑/拖动不误触关闭；真正点击背景/关闭按钮/Escape按既定层级关闭。新增结构复用共享基础组件与语义tokens。

验收不承诺所有未来输入永无bug，使用可复现边界、相关全量回归、同状态DOM/截图及新Tauri证据判断本批通过。真实后端/在线Ardot/缺失Frame/用户最终视觉验收仍由原任务承担。
