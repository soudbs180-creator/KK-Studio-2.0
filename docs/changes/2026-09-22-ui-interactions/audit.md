## 扩展交互复现与修正

- 添加菜单的关闭原来只处理菜单内部 Escape；焦点返回触发按钮后失效。现使用共享 useDismissible 的顶层栈，触发器重复点击排除外点关闭竞争；空白画布触发时仍允许另一处空白关闭。
- TopBar 的弹窗入口在菜单卸载后失去可回焦对象；开启提示词库等弹窗前先回焦稳定的顶级菜单按钮。
- 任务列表的显式关闭未回焦；TaskPanel 的统一关闭现在回到任务入口。
- 任务详情 Escape 原来关闭整个列表；TaskDetail 独立负责子层 dismiss/初始焦点/回焦，父列表保留。详情为原有非模态层，不伪造真实 Provider 结果。
- 窗口变窄自动折叠侧栏时仍保留隐藏项目菜单；分组可见性包含侧栏状态，折叠时清除菜单/编辑态，保留名称/置顶/删除恢复等会话状态。
