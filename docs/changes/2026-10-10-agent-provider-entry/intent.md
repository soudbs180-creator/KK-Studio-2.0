# Intent：区分首页供应商生成与 Codex Agent 入口

- 关联任务：TASK-AGENT-001
- 日期：2026-10-10
- 用户请求：Codex 已连接时，首页仍提示配置供应商；需要明确供应商、Agent 和伙伴的边界。

## 用户原意

供应商负责实际图片生成服务；Codex 主 Agent 负责对话、画布编排和账号内置生图。首页不能把两者混成一个配置状态。

## 本次范围

- 首页模型弹层明确标记“供应商图片模型”。
- 无 Provider 图片模型时，根据 Codex 连接状态显示可行动的边界说明。
- 提供进入右侧 Agent 面板的入口，复用现有 Agent 连接和 Codex 图片能力。
- 保留供应商配置入口和现有生成任务门禁。
- 共享首页行为变更同步桌面与 Web 版本，从 2.1.12 标记为 2.1.13；移动端版本不因本次桌面入口修复变更。

## 非范围

- 不把 Codex 当作 Provider 注入现有 API 任务管线。
- 不新增凭据、存储 key、模型路由或外部服务。
- 不宣称首页“生成”按钮已经直接调用 Codex 内置生图；直接调用仍在 Agent 面板路径完成。
