# 桌面模型代理规格

- 旧桌面资料没有偏好时使用系统代理。每次新请求重新为目标选择线路。强制直连不继承代理。手动模式保存 HTTP(S) 代理地址，使用本机客户端的用户授权，拒绝在地址中保存凭据。
- 模型检测、文字、生图使用同一原生出站策略。回环始终直连。网络设置显示每类最近一次请求采用的线路。系统策略没有匹配代理时显示直连。
- 已选择的代理连接失败时保留现有错误及任务语义。生成不会切换线路并重发。
- 供应商端点必须通过既有协议、公有地址和停止重定向检查。代理是用户信任的网络边界。只下载既有规则允许的同源图片，复用生成请求的线路与客户端，下载不附供应商密钥。
- 保存失败保留原设置。Web 不提供桌面出站设置。
