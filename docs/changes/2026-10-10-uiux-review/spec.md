# Specification

- 图片卡片与生成结果保存自然宽高，预览按 `aspect-ratio` 渲染并使用 `contain`。
- 图片卡片上传入口位于卡片外上方，名称位于卡片右上角，工具条在卡片上边缘；爱心属于卡片操作。
- 删除按钮默认中性，仅 hover、focus 或 active 呈现危险色；参考图关闭按钮默认隐藏，悬停或键盘聚焦时显示。
- 首页、画布卡片和会话助手的控件采用同一 32px 胶囊规格；输入文字不触发外层发光；生成数量菜单扩大字号与命中区。
- 任务弹层扩大为可读布局；无名项目不在画布状态条显示。
- 模型菜单按 Agent、图片、视频、音频分场景；Skill、插件/MCP、智能体共用扩展入口；助手保持主 Agent 优先。
- Agent 参考图和连接状态区域按“执行方式—状态—引用—输入”排序并居中呈现。
