# Desktop Agent 托管规格

- Windows 桌面设置提供启动并连接、停止服务和实际状态。Web 继续外部本地服务连接；资源缺失显示原因。启动不自动发模型 turn。
- Tauri 从自身资源目录定位随包 Node、Agent 和 Codex 执行文件，不依赖开发仓库或全局 PATH。独立打包命令准备资源并传入 Tauri resource config；普通无资源构建仍可用并诚实提示不可启动。
- 每次实例绑定系统分配的 loopback 端口和随机内存 token。配置使用 KK 数据目录内专用 agent 目录，保持 Codex 现有登录身份，不复制或改写 auth.json，不复用项目 Provider 密钥。
- 子进程等待原生主进程确认归属后才启动服务。Windows Job Object 管理整个子树；停止、启动失败和主进程退出均回收，只管理本次实例的子进程。外部已运行 Agent 不受影响。
- 启停串行；重复启动返回同一实例；健康与连接独立展示；连接失效不能标运行成功；进行中的 turn 必须先走既有停止/结果核对流程再停止服务。
- 打包只收集运行代码与生产依赖（排除意外的 kk-studio 源码链接）、Node/Codex、许可证与 SHA-256 清单，禁止用户配置/日志/会话/凭据。vendor 仍隔离于 KK 业务源码与 UI 门禁。
- 验收：真实桌面设置点击启动/连接/停止/重启，拥有权与退出清理、两次启动配置/会话恢复、资源字节校验；完整 verify、Rust checks、独立 dirty-diff 预检。模拟服务证据与真实 Codex 请求分别记录。
- 其他登录软件、网页并发、非兼容 API、音视频、附件/参考编辑、通用第三方 MCP 逐项保留其实际边界；不以桌面托管验收替代这些能力。
