# Figma 复刻一致性审计规格

本规格从同目录 `intent.md` 抽出可验收定义。它不新增产品界面改动。

## 验收分层

| 层 | 含义 | 可验收标准 |
| --- | --- | --- |
| L1 结构 | 图层树、组件变体、命名映射 | 组件名与变体键可对照 |
| L2 令牌 | 颜色、字阶、间距、圆角 | `DESIGN.md` 与 CSS 变量可对照，含别名分歧 |
| L3 几何 | 坐标、尺寸、盒模型 | 节点矩形可对照，容差不超过 0.5px |
| L4 像素 | 位图逐点 | 不做严格相等；只记录有界差异和容差 |

严格逐点像素相等不作为验收条件。Figma 导出高度与本地视口可能差 1px，比对前裁到共同区域。

## 范围

- 来源登记、快照拉取、L1–L3 比对、L4 像素比对和命令入口。
- 令牌只从环境变量读取。
- 历史快照不能当作现行门禁基线。
