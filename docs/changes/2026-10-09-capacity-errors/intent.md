# TASK-PROV-007 — intent

## 问题

"Selected model is at capacity" 等上游容量/429 拒绝被压成普通 Error：当前
代码只把所选模型原样发给上游，错误 message 用本地模板替换，原始错误与
HTTP 状态丢失；无容量状态分类、实时可用性刷新、降级选择或明确切换入口；
无 Retry-After 时仍标记可重试。

## 目标

1. 上游 capacity/429 失败分类为容量状态，保留原始错误消息与 HTTP 状态
   （浏览器与原生提交路径都保留）。
2. 没有 Retry-After 时不盲目重试：连接进入冷却（既有 cooldown 门禁），
   提示恢复后手动重试；有 Retry-After 时按秒数提示并保留 retryable。
3. 失败提示明确显示当前可用连接，提供切换/降级引导（设置中切换）。
4. 与 TASK-PROV-006 提交门禁互不冲突（006 管提交前门禁与回执身份，
   007 管失败分类与提示）。

## 非目标

- 不新增独立 models/usage 命令（无既有 usage 端点；可用性由连接健康派生）。
- 不改变队列/自动重试机制本身（BYOK 路径无自动重试）。
