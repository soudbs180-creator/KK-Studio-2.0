# Spec

## 目标

- 派发即创建独立任务分支和 worktree。
- 每个分支只承载一个任务，完成后先自查和验证，再合并回 `master`。
- 禁止长期挂起分支和把多个任务集中到末期合并。
- 合并后在干净 `master` 上复验并记录结果。

## 约束

- 分支名必须包含 `TASK-ID`。
- 默认不允许堆叠分支；硬依赖只能一层且必须登记。
- 未完成或证据不足的任务不得伪装成 DONE，也不得为清理分支而强行合并。
- 当前 `master` 与现有 `main` 已分叉，必须先完成一次基线迁移；不得用旧 `master` 接收当前 `main` 的大包变更。
