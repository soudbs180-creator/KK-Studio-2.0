## 4. 动效（`src/styles/motion.css`）

- 时序令牌：`--motion-fast: 140ms`、`--motion-panel: 220ms`、`--motion-ease: cubic-bezier(0.22, 1, 0.36, 1)`。
- 入场：`surface-enter`（opacity 0→1 + translateY 8px→0）用于弹层/面板；`backdrop-enter` 用于遮罩。
- 拖拽/平移中禁用动画与过渡（`.canvas-node.is-dragging`、`.is-panning .canvas-stage`），避免与变换冲突。
- **`prefers-reduced-motion: reduce` 必须全局关闭动画/过渡/平滑滚动**（两处均已实现）。
- 状态：140/220ms 与曲线为**工程补充**，Figma 关键帧三处递归返回空，未取得原稿时序证据前不得称"还原原稿动画"；取得真实值后按原稿替换。

## 5. 交互标准（新增与既有控件统一遵守）

- 键盘：所有弹层/菜单 Escape 先关闭并回焦触发按钮；二次 Escape 才取消卡片选择；方向键/Home/End/Enter/Space 可用；焦点可见（`focus-visible` 2px `--ui-focus`，offset 3px）。
- 画布：无限画布无页面滚动条（overflow: clip）；缩放保留目标锚点、不移动节点；菜单操作不触发拖动；卡片拖动/键盘移动/删除保留草稿。节点内部禁用浏览器原生 dragstart，避免图片拖放取消 Pointer Events；外部文件 drop 保留。图片卡片的透明外壳不截获鼠标，可见子区域和跟随操作恢复命中，避免遮挡可见连线。
- 连线：悬停/聚焦/选中显示删除按钮，移向删除按钮期间保持显示，点击外部解除激活；删除只移除连接并提供撤销，保留两端节点与内容；节点移除同步清理悬空连接。删除当次操作内回焦画布，避免延迟回焦抢走后续菜单焦点。来源节点位置与草稿不得因连接操作改变。
- 右侧跟随加号：按节点坐标定位，保持屏幕尺寸（桌面 28px，宽度不超过 800px 时 44px），点击打开共享类型菜单，创建下游卡片并选中/聚焦；自动定位按屏幕像素预留按钮空间，不能仅预留缩放后的世界坐标间距。菜单键盘移动不滚动页面。
- 示范素材：显式入口加载图片/短视频/音频/可编辑文案；节点标注"示范素材"，模拟处理标注"演示处理中"；不冒认供应商生成成功、积分消费或保存服务器；不依赖第三方 API，但浏览器仍需能读取本地静态资源（未实现 Service Worker 完整离线缓存）；取消不得出现迟到结果。
- 弹层/预览：关闭与 Escape 回焦；媒体真实可播放（音视频不得用海报假装），加载/错误可恢复；文案可编辑复制。
- 无障碍：语义角色、aria 状态（pressed/checked/expanded）、长中文无截断、四视口（1920/1440/768/390）无页面溢出。

## 8. 可执行门禁与扩展流程

`npm run ui:check` 已纳入 `npm run verify`。检查 `src` 下 CSS/TSX 的具体颜色值及出现次数、未声明且无回退值的 CSS 令牌、TypeScript AST 中的 Lucide 导入符号、Iconsax 导入入口，以及组件 300 行边界。新文件默认没有遗留豁免；新增颜色定义放到 `global.css` 或 `ui-tokens.css` 并在本文登记用途，表现层只消费令牌；新增补充图标先进入 `UiIcon.tsx`。本轮排除了不存在的 bg-hover 引用，按钮和菜单统一使用 bg-card-hover。

`config/ui-legacy-baseline.json` 明确保留现有原始颜色值及 Lucide 符号，后续有来源的迁移逐步减少。不能通过更换字面值、向现有 import 加图标或扩大基线绕过规则。本轮将粗略数量清单收紧为具体值/符号，未增加产品用法。基线还包括未完成校对的设置、资产、搜索等旧实现，不能理解为这些页面已经全部统一。

新页面实施顺序：读取对应 Figma 节点及状态 → 复用令牌、UiIcon、Modal/useDismissible 等组件 → 检查点击/键盘/取消/失败与恢复 → 同状态截图和四视口核对 → `ui:check` 及适当回归 → 将实际结果与差异写入 PROGRESS。门禁不理解设计语义，不校验像素还原、对比度或真实触屏体验；这些仍需来源与浏览器证据。

门禁验证：临时负向探针分别触发原始颜色、新 Lucide 符号、直接 Iconsax 导入三项失败；探针已移除，54 个文件零违规。证据在 `evidence/frontend-standards-2026-09-07/ui-check-negative-final.log` 和 `ui-inventory-final.json`。

2026-09-07 设置页收敛：`settings.css` 的 23 处颜色字面量全部改为共享令牌，移除该文件的遗留颜色豁免。深色来源数值保留；浅色采用全应用语义色，属于工程补充。开关滑块沿用 40×20/20×14 原稿几何，关闭位置为原稿 6.67%（2.667px）、开启位置 40%（16px）；过渡消费 motion-fast/motion-ease，仍不是 Figma 时间轴还原。

## 9. 画布控件布局标准（2026-09-08）

> 后续同日用户批注纠正了下方“收起工具栏”“独立示范入口”的用途；以第10节为准。历史测量保留，但不能再作为这些错误用途的验收要求。

- 屏幕上的工具（任务、示范、导航、对话入口）统一组合于 `CanvasHud`。由同一个 `useCanvasViewport` 计算实际可用内容宽度（排除画布边框、停靠聊天与16px间隙）；窄屏打开聊天抽屉时也必须扣减可用宽度，保证底栏不被面板覆盖。顶部控件保持同一行和固定 8px 组间距，窄屏展开入口排在导航最右侧。底栏中心也消费该宽度，不再维护多套聊天宽度常量。
- 原稿有分工差异的控件不能统一拉伸：170:8361 底栏保持266×50，添加/选择/收藏/资产槽40px、收起槽20px、帮助30px，原稿间距和分隔线。390px仍容纳完整266px，不把各按钮压成不一致宽度。100:16335 导航内部继续使用47/6/20/20/55px列轨道；缩放组和功能组之间使用8px工程间距，组合宽度为235×26，避免和右侧面板开关形成不等距空隙。
- 跟随加号和删线按钮按世界坐标锚定，先抵消画布缩放，再按屏幕坐标居中/偏移：加号屏幕间距8px，删除按钮中心在连接曲线中点；不要在世界坐标中减固定14px。28px桌面与44px窄屏命中区沿用前端补充规范；菜单始终在按钮下方留6px。自动定位预留52px屏幕空间（8+44），不把此空间乘缩放。
- 工具栏收起/展开保留焦点和 `aria-expanded`，关闭残留菜单。固定网格不使用宽度插值（会在窄胶囊中提前铺开子按钮）；新按钮使用140ms淡入，禁用按钮维持禁用透明度；reduced-motion关闭动画。新Figma动效读取返回nodes=[]，这些时间与响应式规则是工程补充。
- 验证需同时覆盖窗口宽度、面板状态、画布比例三个维度，断言真实矩形交叠和命中位置，并查看截图；只检查页面scrollWidth不足以发现控件相互覆盖。

## 13. 尺寸层级与复用契约（2026-09-09）

- 文字、图标和容器按同一组共享令牌分层：`--ui-font-caption`（11px）用于辅助信息和项目行，`--ui-font-body`（12px）用于正文和普通控件，`--ui-font-label`（14px）用于导航，`--ui-font-title`（16px）用于面板标题；禁止在单个页面重新定义同义字号。
- 图标槽位使用 `--ui-icon-xs`（14px）、`--ui-icon-sm`（16px）、`--ui-icon-md`（20px）；侧栏图形槽使用 `--ui-icon-sidebar`（22px），导航组图标使用 `--ui-icon-nav`（10px）。普通紧凑控件使用 `--ui-control-h-compact`（30px），导航条使用 `--ui-control-h-nav`（26px），画布工具槽使用 `--ui-control-h-standard`（40px）。视觉图形可以小于槽位，但命中框和对齐基线不能跟随图形缩放漂移。
- 间距只从 `--ui-gap-tight`（4px）、`--ui-gap-standard`（8px）、`--ui-gap-relaxed`（12px）选择。画布右上角缩放组、导航组和收起开关属于同一 `canvas-hud-right`，组间固定8px；会话标题按钮固定30×30并锚定到该基线，避免窗口缩放或聊天宽度变化造成跑偏。
- 会话输入区始终保持单行，控件以 4px 间距和 30px 高度排列；自动/询问合并为一个模式按钮并通过弹出菜单选择。每个按钮保留可访问名称、实际动作或明确禁用原因。窄屏打开会话面板时，`useCanvasViewport`同步扣减面板宽度，工具栏与节点操作区必须保持在面板左侧。
- 复用检查以真实矩形为准：至少覆盖 1071×698、1440×900、1600×1047 和 1920×1080；检查导航等距、标题按钮尺寸、输入控件不溢出、工具栏与会话面板无交叠。证据写入 `docs/evidence/release-2026-09-09/ui-geometry.json` 及对应截图；`composer-fidelity.spec.ts` 同时断言标题图标 20px、输入区主图标 20px/辅助图标 16px，防止通用规则把局部图标意外压小。

## 10. 最新用途和复用契约（2026-09-08）

- `useCanvasPointer`统一手势归属：选择工具下左键从空白起拖为框选，从卡片可见内容起拖为移动；中键/右键或抓手工具平移视图。Shift点击/框选追加多选；拖动已多选卡片同步移动。Space临时平移，V/H切换工具；输入、中文合成、弹层及菜单不接管普通文本键。Escape/指针取消/窗口失焦取消正在进行的手势并恢复坐标，不留下抓取状态。
