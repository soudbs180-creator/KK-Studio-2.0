## 先说清楚一件事

> **当前版本没有独立的「请填写 API Key」弹窗。**
> 密钥是在「设置 → 模型接入」**页面内的表单输入框**里填的（`ProviderApiKeyField.tsx`）。所以本文说的「弹窗」，指的是**设置窗口 / 设置面板**（标题「设置」），以及其中的配置表单；任务里设想的「AI 提交草稿 → 弹出安全输入框」目前是 **【待界面落地】**。

## 0. 开始之前

- 先准备好服务商的 API Key。**只在应用界面的输入框里填**，不要发给 AI、不要贴进聊天、不要写进文档。
- 连接测试或保存进行中时，界面会锁住导航和「关闭设置」，提示「连接操作进行中，完成后可切换设置」/「连接操作进行中，完成后可关闭」。等它跑完再动。

## 1. 打开设置窗口

| 顺序 | 你看到的名称 | 你要做什么 |
| --- | --- | --- |
| 1 | 左侧边栏的齿轮按钮（无障碍名「打开设置」） | 点它 |
| 2 | 设置面板标题「设置」 | 确认已打开设置窗口 |
| 3 | 右上角「关闭设置」 | 配完再点；窄屏还有「返回设置分类」 |

## 2. 进入模型接入

| 顺序 | 你看到的名称 | 你要做什么 |
| --- | --- | --- |
| 1 | 左侧「设置分类」导航里的「核心功能」分组 | 找到该分组 |
| 2 | 「模型接入」 | 点它 |
| 3 | 页面标题「模型接入渠道」 | 确认进对了页面 |

## 3. 选渠道标签

页面上方是「模型接入渠道」下的渠道标签，选一个：

| 标签 | 徽标 | 选中后的面板标题 | 什么时候选 |
| --- | --- | --- | --- |
| 「官方直连」 | API | 「官方 API 直连 (Official API)」 | 用 OpenAI / Claude / DeepSeek 等官方 API |
| 「中转路由」 | Gateway | 「API 供应商路由 / 中转站 (Relay)」 | 用中转站、聚合网关 |
| 「账号授权」 | OAuth | 「账号授权 (OAuth / Web Authorization)」 | **默认不显示**（源码按环境变量控制），别找它 |
| 「CLI 直连」 | CLI | 「CLI 直连 (Native CLI Runtimes)」 | 用已登录的本机命令行工具 |
| 「本地模型」 | Offline | 「本地模型 (Local Runtimes & ComfyUI)」 | 用本机 Ollama / LM Studio / llama.cpp |

- 「官方直连」「中转路由」「本地模型」三个标签下才会出现本文第 4 节的 API 表单，对应区块分别是「官方 API Key 配置」「中转站 API Key 配置」「本地模型服务」。
- 「本地模型」下面还有一节「已启动的本地对话服务」，说明里写着连接 llama.cpp、LM Studio 或 Ollama 默认无需 API Key。
- 「官方直连」页下方另有「Google API」区块（Google Gemini 配置），本文以通用 API 表单为主。

| 名称 / 文案 | 类型 | 填什么 / 做什么 |
| --- | --- | --- |

## 5. 连通测试怎么看成功 / 失败

### 5.1 点哪里

点「**测试连接并刷新模型**」。测试期间按钮变成「**取消测试**」，状态条显示「**正在请求模型列表…**」；点取消后显示「正在取消连接测试…」。

### 5.2 成功长这样

- 状态条标题从「API 连接」变成「**模型列表已获取**」。
- 消息：「**已获取 N 个模型；生成能力仍需实际验证。**」（N 是拉到的模型数）。
- 「模型目录」自动出现模型，可以点「选择」或「☆ 设为默认」。
- **注意**：这只是**列模型成功**，不等于能出图。「已登记连接」里的「已验证生成」要等一次真实图片生成成功才会出现。

### 5.3 失败 / 取消 / 离线逐条对照

| 你在状态条看到的原文 | 意思 | 建议动作 |
| --- | --- | --- |
| 「无法连接，请检查地址、网络和服务的跨域访问设置。」 | 地址不通或跨域被挡 | 检查「接口地址」、网络代理、服务端跨域设置 |
| 「设备处于离线状态，请联网后重试。」 | 本机离线 | 联网后重测 |
| 「网络已断开，请恢复后重试。」 | 测试中断网 | 恢复网络后重测 |
| 「连接超时，已取消请求。」 | 超时被自动取消 | 检查网络 / 代理，重测 |
| 「已取消连接测试。」 | 你点了「取消测试」或切走了页面 | 想测就再点一次 |
| 「连接在检测期间已变化，未更新模型目录；请重新选择连接后检测。」 | 测试期间配置被改过 | 回「已登记连接」重选，再测 |
| 「密钥无效或未授权 · Nms (HTTP 401/403)」 | Key 不对或没权限 | 用「清除密钥」后重填，再测 |
| 「服务响应异常 · Nms (HTTP xxx)」 | 服务端报错 | 看服务商状态，稍后重测 |
| 「连接响应超时（超过 Nms 阈值，请检查网络代理）」 | 快速测速超时 | 检查代理后重测 |
| 「此配置未明确选择账号，请先在已登记连接中选择要使用的账号。」 | 同地址有多条连接，没选清楚 | 回「已登记连接」选一条 |
| 「请检查供应商配置。」 | 表单校验没过 | 检查「提供商」「接口地址」「模型名称」 |

保存（不是测试）失败时的原文：「**无法保存连接信息或系统凭据，原密钥和草稿已保留；请检查权限后重试。**」——按提示检查系统凭据库权限，不要反复重填 Key。

### 5.4 一句话判断

- 看到「**模型列表已获取**」＝ 成功。
- 看到「**无法连接…**、**超时…**、**已取消…**、**网络已断开…**」＝ 没成功，按上表处理。
- 任何情况下都**不要**把「未验证生成」当成「已能用」。

## 6. 保存之后还要做什么（可选）

- 点「保存连接」→ 看到「连接信息已保存。API Key 不会写入浏览器存储或项目快照。」
- 到「模型目录」点「选择」挑模型、需要时点「☆ 设为默认」。
- 想确认真能出图，跑一次真实生成；「已登记连接」出现「已验证生成」才算数。
- 配完点「关闭设置」。

## 7. 失败如何回滚（当前版本真正能做的）

**先说结论：当前界面没有「一键撤销 / 快照回滚」按钮，这一项是【待界面落地】。** 现在能用的是下面 6 种手动恢复方式：

| 情况 | 怎么恢复 | 依据 / 你会看到 |
| --- | --- | --- |
| ① 测试失败 | **不用回滚**：测试不写入已保存配置，草稿还在，改字段再测 | 状态条「有尚未测试的更改。」 |
| ② 保存失败 | **不用回滚**：原密钥和草稿都保留，检查权限后重试 | 「无法保存连接信息或系统凭据，原密钥和草稿已保留；请检查权限后重试。」 |
| ③ Key 填错 | 点「清除密钥」→ 重新在「API Key」输入框填 → 再点「测试连接并刷新模型」 | 「已清除当前供应商的密钥。」；「密钥已更改，请重新测试连接。」 |
| ④ 配置改错了 | 在「已登记连接」里点回原来那条连接 → 点「保存连接」 | 「已选中连接供编辑；保存后生效。」 |
| ⑤ 切到别的渠道又切回来 | 草稿会自动保留，不会丢你刚填的内容 | 切换渠道时把草稿存起来，切回时恢复，并提示「有尚未测试的更改。」 |
| ⑥ 测试中想退出 | 先点「取消测试」，等「正在取消连接测试…」结束再点「关闭设置」 | 进行中导航和关闭按钮是锁住的 |

**【待界面落地】**：`kk_config_rollback` 对应的快照回滚、「已修改，可撤销」通知与一键撤销按钮，目前只在后端 / 设计稿里，界面上没有控件。AI 如果说「点一下就能撤销」，让它先指给你看按钮在哪；指不出来就按上表手动恢复，别假装已经回滚。
