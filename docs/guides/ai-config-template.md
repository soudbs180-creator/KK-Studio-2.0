# KK Studio 配置单模板（复制填好，直接发给 AI）

> **这是什么**：一份「一页式配置单」。把下面【配置单开始】到【配置单结束】整段复制，替换 `{{...}}` 里的答案，发给 AI 就行，不需要懂技术、不需要自己改代码。
> **配套文档**：[UI 对照弹窗说明 · 照着界面点](./config-dialog-walkthrough.md) —— 里面写清每个按钮叫什么、连通测试成功/失败长什么样、失败怎么恢复。
> **日期**：2026-11-09　**适用范围**：KK Studio 桌面端「设置 → 模型接入」的当前版本。

## 先记住一句话

> **Key 只在弹窗里填，不要贴进聊天、文档，也不要发给 AI。**
> 本模板里 Key 那一栏只是一个「**这里不要填**」的占位符，不是让你填密钥的地方。

## 怎么用（3 步）

1. 复制下面整段配置单。
2. 把每个 `{{...}}` 换成你的答案；**第 7 项 API Key 不要换、不要填**。不知道写什么就填「不知道，请先帮我探测」。
3. 发给 AI。AI 会先读现状、说明要改什么，需要密钥时**让你在应用界面的输入框里自己填**，然后跑连通测试；花钱或有风险的动作会先问你。

## 配置单（复制从这里开始）

```text
请按下面这份配置单，帮我在 KK Studio 里接入一个模型。

【1】要接哪个模型 / 供应商
- 供应商或渠道：{{供应商名称，例如：DeepSeek / OpenAI / 自建中转站 / 本机 Ollama；不知道就写「不知道，请先帮我探测」}}
- 主要用途：{{对话 / 生图 / 视频 / 反推提示词，可多选}}

【2】Base URL（接口地址）
- Base URL：{{例如 https://api.example.com/v1；不知道就写「不知道，请用服务商预设填入」}}

【3】模型名
- 模型名 / 部署名称：{{例如 deepseek-chat；不知道就写「不知道，请连通后从模型目录里选」}}

【4】权限级别（只选一个）
- 权限级别：{{L0 / L1 / L2}}
  L0 = 只看不改（读配置、列能力、连通测试）
  L1 = 本地可逆改动可直接做（保存连接、改默认模型、改默认路由），但必须事后告诉我「已修改，可撤销」并说明怎么撤销
  L2 = 花钱或有风险的动作必须先问我（超预算生成、下载大模型、删除数据、对外发送、切换主 Agent、把图片发到云端）

【5】本地还是云端
- 运行位置：{{本地 / 云端 / 都可以，优先本地}}

【6】预算上限
- 周期：{{每日 / 每月}}
- 金额上限：{{¥ 数字，例如 ¥50}}
- 超预算时：{{先问我 / 直接拒绝}}
- 说明：额度内的付费动作可以自动执行，不用每次问我；没设预算前不要执行任何付费生成。

【7】API Key
- API Key：{{API_KEY_请勿填写}}
- 硬性要求：Key 只在弹窗里填，不要贴进聊天。我不会把 Key 发给你，你也不要向我索要、
  不要写进任何文档 / 日志 / 配置文件 / 聊天记录，不要回显，不要把 Key 复制给别人。
  需要密钥时，只提醒我去应用界面的输入框里自己填，然后等我填完再继续。

【8】执行与验收要求
- 先读当前配置并打快照，再改动；每一步给我一个可检查的结果，没通过就停下，不要跳步。
- 界面名称以实际界面为准；当前版本没有独立「请填 API Key」弹窗时，指引我去
  「设置 → 模型接入 → 官方直连 / 中转路由 / 本地模型」的 API Key 输入框里填。
  源码里找不到的入口标「待界面落地」，不要编按钮名，也不要假装配置成功。
- 填完 Key 后跑一次连通测试，把「模型列表已获取」或失败原因原样告诉我。
- 失败时保留原配置和原密钥，列出恢复步骤；不要写「已配置成功」。
- 改完后告诉我改了什么、怎么撤销；撤销入口如果界面还没有，如实说「待界面落地」。
- 不修改应用源码，不关闭安全检查，不读取或回显密钥。
```

**配置单结束**。

## 安全红线（复述底稿，别省略）

- **Key 只在弹窗里填，不要贴进聊天**；不写进文档、日志、配置文件、导出包。
- 不读取、不回显密钥；AI 也不得索要密钥。
- 未经确认不下载本地大模型、不删除数据、不切换主 Agent、不超预算生成。
- 不修改应用源码，不关闭安全检查。
- 连通测试没通过就停下，如实说明原因，不写「已配置成功」。

## 三个常见问题

| 问题 | 怎么办 |
| --- | --- |
| 我不知道 Base URL / 模型名 | 在「服务商预设与快速填入」里点「一键填入」，或让 AI 连通成功后从「模型目录」里选；见 [UI 对照说明第 4 节](./config-dialog-walkthrough.md) |
| Key 填错了 | 点「清除密钥」→ 重新填 → 再点「测试连接并刷新模型」；见 [第 7 节](./config-dialog-walkthrough.md) |
| 测试失败会把原来的配置弄坏吗 | 不会。测试失败不写入已保存配置，草稿还在；保存失败时提示「原密钥和草稿已保留」。见 [第 7 节](./config-dialog-walkthrough.md) |
