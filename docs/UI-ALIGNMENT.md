## 逐项核对顺序

1. 获取最新画板及相邻状态图，区分默认态、悬停、选中、编辑、菜单展开；记录能从原稿确认的触发方式。
2. 核对主界面的侧栏、画布、对话区、工具栏的位置、尺寸、边距和层级。历史 1920 坐标只作参考，不作最新稿的强制基线。
3. 核对卡片的上传入口、标签、预览区域、选中边框以及下方编辑器；逐项检查图片、视频卡片是否有不同状态。
4. 核对空白处操作、卡片拖动、视图缩放、点击选择和取消选择，确认输入框/按钮操作不误触画布。
5. 核对模型、参数、数量等菜单，以及对话、设置、资产等现有面板的打开、切换、关闭及焦点返回。
6. 每修正一个界面，保存原稿与实现的同状态截图，并执行对应操作路径；交互测试应验证原稿要求，不应仅锁定既有实现。
