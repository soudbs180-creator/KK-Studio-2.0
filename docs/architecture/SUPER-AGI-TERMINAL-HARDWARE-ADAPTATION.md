## 二、 硬件感知：本地模型最优动态匹配体系

为什么自己折腾本地模型容易头大？因为**显卡显存（VRAM）和内存（RAM）太容易被撑爆（OOM 崩溃）**。  
超级 AGI 终端通过 Rust 底层硬件探测（[`src-tauri/src/local_hardware.rs`](file:///D:/kk-studio/KK-Studio-2.0/src-tauri/src/local_hardware.rs)）与推荐算法（[`src/domain/localModelRecommendations.ts`](file:///D:/kk-studio/KK-Studio-2.0/src/domain/localModelRecommendations.ts)），实现**全自动显存自适应**：

```mermaid
flowchart TD

    Classify{"⚡ 算力档位评定 (Compute Tier)"}
    
    Probe --> Classify

    Classify -->|Tier 1: 极速入门<br/>VRAM < 8GB 或 核心显卡| Low["轻量蒸馏配置<br/>• LLM: Qwen 2.5 7B (Q4_K_M, 4.5GB)<br/>• 绘图: SD 1.5 极速版 或 FLUX-schnell 4-step<br/>• 超分: Real-ESRGAN 轻量无头"]
    
    Classify -->|Tier 2: 黄金主力<br/>8GB <= VRAM <= 16GB (3060/4060/4070)| Mid["均衡工业配置 (推荐)<br/>• LLM: Qwen 2.5 14B / DeepSeek 蒸馏 14B<br/>• 绘图: FLUX.1 [dev] 8-bit 或 SDXL 满血版<br/>• 超分: Topaz Gigapixel CLI / 4x-UltraSharp"]

    Classify -->|Tier 3: 满血旗舰<br/>VRAM >= 24GB (3090/4090/Mac 64G+)| High["全尺寸旗舰配置<br/>• LLM: Qwen 2.5 32B / 72B (Q4/Q8)<br/>• 绘图: FLUX.1 [dev] FP16 满血版 + LoRA 串联<br/>• 扩图: 本地 Photoshop UXP 或 ComfyUI 高清重绘"]
```

### 显存动态哨兵机制（Dynamic VRAM Guardian）
1. **防爆显存保护**：保留 2GB 专用显存给操作系统与显示器渲染，绝不贪婪占满；
2. **用完即释放（Zero VRAM Creep）**：
   - 当大模型推理完成后，若用户发起高显存绘图任务，Agent 自动将 LLM 挂起释放显存，腾出空间给绘图模型；
   - 绘图完成自动回收显存，恢复待命状态。用户永远不会看到黑屏闪退。

## 三、 用户体验引导：您该怎么用？

您完全不需要向任何人学习复杂的“AI 提示词工程”，只要在超级终端里像对合伙人说话一样表达：

### 场景 1：想在本地完全离线做图
- **您说**：“我想全靠本机显卡，画一张赛博朋克风的少女插画，要细节最清晰的。”
- **超级终端自动做**：
  1. 检查当前显卡（例如发现是 RTX 4070 12GB）；
  2. 自动选用 `FLUX.1-dev-Q8` 搭配本地最优 Clip 编码器；
  3. 执行绘图并在完成后自动调用本地超分放大到 4K；
  4. 产物直接呈现在画布中心。

### 场景 2：想改软件某个功能，但觉得超纲了
- **您说**：“我觉得画布左下角的工具栏放太多图标了，能不能帮我把不常用的收进一个二级气泡里，但是常用的放外面？”
- **超级终端自动做**：
  1. 调取 Figma 规范与本地代码；
  2. 自动重构 `CanvasToolbar.tsx`，提取二级气泡组件；
  3. 执行 `npm run tokens:check` 与 `npm test` 确保无任何回归；
  4. 刷新画布，向您汇报：“已经重构完毕，常用保留 3 个，其余收纳至二级菜单，门禁全绿。”
