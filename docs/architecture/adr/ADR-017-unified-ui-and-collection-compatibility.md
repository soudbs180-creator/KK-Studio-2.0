# ADR-017：统一 UI 与画布分类的兼容边界

- 状态：ACCEPTED（决定采纳；实现和发布验收仍以任务证据为准）
- 日期 / Task ID / Owner：2026-10-14 / TASK-UI-CONSOLIDATE-20261014 / root
- Intent / Spec / Plan：[用户意图](../../changes/2026-10-14-ui-consolidation/intent.md)、[规格](../../changes/2026-10-14-ui-consolidation/spec.md)、[计划](../../changes/2026-10-14-ui-consolidation/plan.md)
- 决策依据：用户明确默认绿色、胶囊居中、输入不出现明显外圈，喜欢和标签为固定大小且可自由拖动的独立页面。
- 替代关系：补充 ADR-015 的 UI 运行体系；局部覆盖旧颜色、按钮和收藏页面约束，旧记录保留原义。

## 背景和约束

旧顶部喜欢、搜索收藏双栏、过窄模型入口与多套局部样式混在一起。把收藏直接删掉或改存标签会丢失旧版本语义；把面板放进画布世界变换又与用户“固定大小”要求冲突。恢复阶段源版本、分支和证据已冻结，不能把旧验收推到新 UI。

## 方案比较

| 方案 | 代价与取舍 |
| --- | --- |
| 保留搜索/喜欢/收藏同一弹窗 | 数据改动少，但继续混合分类与偏好，不满足独立面板 |
| 删除 favoriteIds 并全量迁入标签 | 格式更少，但旧客户端/项目包会失去收藏语义；回滚写入可能丢数据 |
| 保留字段、投影收藏标签、屏幕面板 | 采用；兼容旧资料，分类和偏好分开，仅位置属于界面偏好 |

## 决定

UI_INDEX 路由当前用户反馈，tokens.css 是唯一运行时数值源。普通主要动作中性、默认强调绿色；上传方形圆角、文字动作自适应胶囊。具体控件规则留在 UI_RULES / DESIGN-SYSTEM，ADR 只记录边界和取舍。

likedIds 表示喜欢。favoriteIds 保留旧收藏，读取通过 effectiveTags 显示“收藏”虚拟标签，编辑通过 splitCollectionTags 回写收藏字段与普通 tags；普通分类不占用喜欢。tags/customTags 是可选新增字段，普通标签最多 32 个、每项 40 字符，虚拟收藏可额外展示；不为兼容而静默截断第 32 项。浏览器 codec、原生快照和项目包保持相同验证/回载契约，存储身份与 schema 主版本不变。

FloatingCollectionPanel 放在屏幕层，尺寸消费注册 tokens，不跟随画布平移缩放。两面板独立开关、搜索、位置与回焦；位置通过非敏感浏览器偏好键保存，项目切换重置编辑草稿，项目数据仍保留在原快照。窗口变小时钳制可达位置，拖动把手和内容动作不冒泡为画布移动。

资源库管理已归档原件与来源；存储管理位置、占用和恢复；使用记录从当前设备项目/任务实际回执派生。已加载资源页不代表完整库；未知 Token、缺失费用/历史生成量保持未报告，不由字数、quota 百分比或 demo 推算。

公共预设与协议执行分开。每项提供官网、密钥/认证说明与 API 文档，地址取用户实例或公共端点策略；未接协议显示禁用原因，不自动联网或借用网站登录。Desktop/Web 共享语义，当前窄屏属于响应式 Web，Native Mobile 留在独立 mobile/ 工程与真机验收。

## 迁移、恢复与退出

按原件快照保留 likedIds、favoriteIds、标签和项目包；先验证旧收藏可见，再验证取消收藏标签后保存/重载不复活。坏数据与写入失败保持恢复路径，不产生空快照覆盖；旧版本不认识标签字段时可能拒绝新包，降级写入须先核对兼容而非删除字段。

回退本轮代码/产物不删除用户原件、凭据或恢复 refs。位置丢失只回到可达默认值；模型/CLI 登录和系统凭据保持原身份。分支内容承接与 squash 等价通过具体文件/树验证，不把非祖先分支全部视为未合入。

## 验证和接受条件

对应 collectionTags、assets、usageSummary 单测、原生标签/项目包夹具，以及 canvas-collection-panels / ui-unification / 既有 browser 状态保存回归。需补本轮 production preview、开发与实际 Tauri 的同状态截图/DOM、旧数据重开和独立 SHA 审查；完整浏览器、真实 Provider、安装器、Hosted、Native Mobile 与用户验收没有通过声明。
