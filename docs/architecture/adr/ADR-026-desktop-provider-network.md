# ADR-026：桌面模型 API 的出站线路

- 状态：ACCEPTED（桌面候选）
- 日期：2026-11-21
- 关联：[桌面模型代理规格](../../changes/2026-11-21-desktop-provider-proxy/spec.md)

在已有原生 TaskHost 客户端统一选择系统线路、直连或手动代理。Windows 采用系统网络 API 解析目标源的代理候选，并遵循启动环境的显式代理和绕行规则。一个请求固定选定一条线路，避免失败后重新投递已受理的任务。

直连及本机解析的 SOCKS 固定到已验证的 DNS 地址。代理负责解析域名时，兼容从本地 DNS 返回的 198.18.0.0/15 合成地址。IP 字面量保持原有地址校验。TLS 仍核验原域名，并禁止重定向。图片 URL 仍须同源，下载沿用本次客户端。网络设置只保存模式和无凭据的手动代理地址，界面的最近线路仅保存在进程内。旧版本忽略独立偏好文件。

保留从系统、应用内部和本机服务已有的网络边界。拒绝把通用本机 HTTP 转发器作为模型请求入口或默认云中转。
