# ADR-010：图片编辑统一 Mask 与任务快照

日期 2026-10-08；TASK-IMAGE-EDIT-001；状态接受（用户授权范围内的 AI 技术决定）。

## 决定

使用原图像素逐行区间作为三个工具共同的编辑区域，不各自实现裁剪或融合。界面缩放变换仅影响显示。原有 CreationTask 增加可选 imageEdit 快照；无快照的历史任务保持原行为。模型源图、mask、有效坐标、原图引用和区域组身份在提交前保存。

<=3个独立范围复用现有独立 task；串行执行且每个候选保留已成功区域。>3整图一个 task，仍由共享 compositor限制像素。Web/native mask使用同一个PNG透明度约定。恢复也经过 compositor，不将未经合成的原生方块发布为完成图片。

## 备选及代价

三套工具逻辑会重复坐标/裁剪/保护；直接发布模型方块无法保护未选像素。新增专用生成队列会与现有审批、重试和恢复分叉。本方案新增可选元数据及mask归档引用，导出需收集这些归档原件。旧schema兼容；非法编辑快照拒绝恢复，不静默降级。

## 回滚

原件不可变，候选另存；用户可以删除候选回到原图。回滚源码前保留项目快照与归档数据，不能把编辑任务作为普通生成任务重新发送。
