# ADR-023：本地模型包的可信安装与自有引擎

- 状态：ACCEPTED（设计已采纳，安装与实际推理尚未实现/验收）。
- 日期 / Task ID / Owner：2026-10-16 / TASK-KK-UNIFIED-20261015 / root
- 来源：[批准规格](../../changes/2026-10-15-kk-unified/spec.md)的 LOCAL/MODEL/MEDIA/REPO；延续 [ADR-019](ADR-019-unified-local-repository-and-optional-account.md)与[ADR-021](ADR-021-native-local-repository-authority.md)。

## 背景与备选

用户要求根据本机配置推荐 Qwen 和 H3，也可选择不推荐的型号；检测目录没有启动、下载或生成副作用。现有素材仓库通过完整 DataURL/Vec 传输，不能承接数十GB模型。Hub包装目录不是已验证引擎，不可把任意 main.py 或找到的exe当成受信启动命令。

采用 Native 流式文件适配器、现有 reqwest/sha2/zip/OwnedJob 和既有Provider/TaskHost。拒绝复用媒体小文件上限、另建下载服务/生成队列、自动修改Hub Python/Torch/Triton、自动运行目录内代码。Web在原生授权协议交付前明确不可用；首批引擎制品是Windows x64，不能在其他架构伪装可运行。

## 单源目录与放置

- 固定模型/引擎版本、来源、字节数、SHA、许可和适配声明集中于版本化JSON，TS严格投影，Rust编译绑定同一目录。保留现有包ID、公开导出和推荐结果；Native不接受前端任意URL、hash、可执行路径或launchArgs。
- 用户明确选目录后才创建会话与窗口范围的opaque授权。准备计划只读检查；点击安装才下载。安装ID稳定，端口/进程凭据不是持久渠道身份；登录不能扩大目录权限。
- 受控子目录拒绝越界/重解析点/冲突，不扫描磁盘。同名Qwen mmproj按型号与revision隔离；H3两个模式共享同摘要的encoder/VAE，下载与空间按唯一文件计算。模型原件留在用户选定目录，不混入项目包。
- 一次安装操作有预先生成的ID、真实进度及取消状态；同时安装返回busy，不增加队列。目标卷独占锁防止另一资料根覆盖同目录，磁盘/文件系统检查以实际目的地为准。

## 传输、验证与恢复

- 固定HTTPS源、受限重定向与公共地址钉住、无用户凭据/代理转发；每次读取有界超时和字节缓冲。禁止完整读入内存或Base64通过IPC传模型。
- 部分文件及记录绑定目录、revision、来源、长度、摘要和放置计划。续传先重新校验磁盘前缀，严格检查206范围及validator；200-on-range不能追加，短体/超量/换源/错误摘要不得发布。
- 同卷临时文件完成sync及完整SHA后原子发布，最后提交包receipt。错误、取消及未知状态保留本次可恢复证据，不把半包称为已安装；既有不同内容不覆盖，不递归清理用户目录。
- 固定引擎ZIP采用磁盘流式解压，验证路径、设备名/ADS、大小写冲突、链接、加密、CRC、压缩膨胀和条目总量；只取允许的server/DLL/许可文件，不执行安装钩子。CUDA两制品成员冲突必须内容一致。
- 关联已有包只读核对GGUF/projector的完整摘要及身份，保留原位置；检测不能执行CLI/HTTP/模型。未知或不匹配的包不升级成已验证能力。

## 按需运行与渠道绑定

- 显式启动或真实任务首次使用时重新核对receipt、资源和执行授权，使用可信系统进程门禁先加入OwnedJob再运行固定引擎；不采用先运行后补所有权的竞态。
- 仅loopback、离线文件、单槽和受限上下文；不启用模型自动拉取、内置Agent/MCP或web UI。清理可覆盖参数的继承环境。私有实例凭据只在Native/子进程内存，不进argv、URL、日志或receipt。
- 管理器只复用自己持有的实例及Job，端口响应不构成所有权。身份/模型/版本/健康不符则失败，不认领LM Studio/Ollama/Hub。停止仅针对自有实例，等待退出后才释放；外部服务仍走原免密loopback连接。
- GPU占用由既有宿主协调的共享资源租约约束；没有该集成时GPU启动保持禁用，不用第二队列或杀其他服务解决。已受理任务沿既有回执查询/归档，重启不自动重发。
- Provider事务保存稳定安装引用，执行前由Native解析一次真实端点/凭据并冻结。普通文本、已加载图片输入、一次真实推理和工具协议验证分开；加载projector不等于图片生成，更不等于Agent工具已验证。

## H3 与付费边界

HiFi是社区派生包；16G是作者显存建议，不是64.7GB权重大小或本机性能证明。安装只处理固定权重和只读依赖状态，第三方加速节点/LoRA不自动安装，不修改既有Hub。许可待核对、运行/加速未验状态贯穿receipt和UI。

本地H3不暗调官方2K或其他付费API。后续混合流程另按所选账号、完整输入条件、授权和计费实现；下载安装成功不意味着工作流或官方再生成可用。

## 验证和接受条件

先保存兼容目录与取消/续传/损坏/路径/故障的RED，再以小型本地HTTP、ZIP和可信系统进程夹具验证完整性、内存界限、归属与外部进程不受影响。模块与实际main/UI/Provider/TaskHost集成分别审查，不将零生产调用的适配器标可用。

当前实际大文件传输、固定ZIP布局、CUDA兼容、真实Qwen文本/看图、H3工作流及峰值资源仍未验收。用户主动选择安装后才进行真实资源操作；合成测试不替代这些结果。
