# ADR-036：持久多模态任务与生产去演示

- 状态：ACCEPTED；真实服务终验另记
- 日期：2026-11-04
- 范围：Desktop/Web；Mobile 本轮不变

## 决定

复用 CreationTask、统一提交/审批/任务态、原生 TaskHost journal 与 AssetPort；扩展可选 media 参数、附件角色/首尾帧及逐输出受理回执。保留旧字段和快照身份，旧项目无 media 字段可读取；提供字段时严格校验，项目包无损往返。

视频复用已有 12AI adapter（官方 Veo 异步协议），语音复用已有 OpenAI speech helper。拒绝另建音视频队列、同步接口冒充异步视频及固定素材降级。未知模型/参考格式需明确拒绝；Veo 不消费视频/音频参考，音乐协议尚未接入。

## 恢复与安全

先持久化受理声明，再 POST，再保存已受理 ID；重启仅 GET 原 ID。没有可靠回执时 unknown，不自动重发。供应商不支持远端取消时只停止等待并保留受理不确定。语音无任务查询接口，不能用再次 POST 恢复。Desktop 持久作业不依赖 WebView 生命周期；Web 按原受理回执显式继续查询。

凭据只在宿主/请求内存；拒绝回执和 URL 中的原文或解码后密钥回显。下载不携带认证/Cookie，不跟随重定向，原生固定 DNS 地址，限制媒体大小并核对 MIME/签名后归档。来源或绑定变化后迟到结果不写入画布。合法任务 ID 上限统一 240 字符。

## 兼容与回滚

扩展字段可选，不修改用户数据身份；固定 demo 只保留显式夹具与历史项目读取。回滚代码前先保留媒体原件与快照，不将未识别字段静默剥离。真实付费调用需独立授权；合成协议与播放回归不代表 live 出片质量。
