# KK Studio Mobile

Independent phone creation client using Expo SDK 57 and React Native. This project implements the approved [Mobile specification](../docs/changes/2026-10-17-web-release-receipt/spec.md) and consumes the versioned pure `@kk-studio/creation-contracts` package. It does not import the Desktop/Web runtime.

From this directory, install with `npm ci` and start with `npm start`. From the repository root, `npm --prefix mobile run web` starts a browser preview at port 8081. Verify with `npm --prefix mobile run typecheck`, `npm --prefix mobile test`, `npm --prefix mobile run lint`, and `npx expo-doctor` in the mobile directory. `npm --prefix mobile run export` produces platform bundles; this is distinct from a native installed app. `npm --prefix mobile run android` and `npm --prefix mobile run ios` require the platform SDK and available device/simulator. Native folders are generated by Expo prebuild and are ignored.

Web starts in local mode without a fabricated identity. Local projects, drafts and originals are preserved in an isolated Mobile IndexedDB namespace; optional account mode uses its own verified realm. Desktop Web data remains in its original store and is accessible from Settings. Gateway/Comfy execution requires a verified account. This does not deploy a production identity service.

The default identity URL is `https://kkai.plus`. A webpage at this URL does not prove its phone authentication API is available. Account sessions and Provider keys belong in the platform credential vault; project data and originals stay on the device. A browser preview retains credentials only in request memory and uses IndexedDB for non-secret project data. Never put secrets in a `.env` public variable or exported project.

Current implementation, independent reviews and missing real-service/device acceptance are recorded in the [verification](../docs/changes/2026-10-17-web-release-receipt/verification.md). Do not treat a bundle, fixture or browser preview as native or Provider acceptance.
